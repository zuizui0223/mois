# MOIS 2024 全陸域の白色ROI成分 × 同年VIIRS光量：原本空間対応、島内候補の頑健性（2026-11-07）

## 実測同年データに基づく、空間的対応（変化回帰ではない）

**2024年の原画像を新規に取得・再推論せず**、凍結済みの MOIS canonical (1 photo / observation ID)、GSHHG 2.3.7 元陸塊、WorldPop Global2 R2025A v1 の2024年人口（人数/30″セルをWGS84測地面積で人口/km²へ換算）、VIIRSの2024年Jan/Apr/Jul/Oct raw月別上向き放射輝度を対応させた。2020年WorldPop Global1の人口値は流用していない。人口欠測・薄雲による品質不足をゼロ補完しない。島の面積・緯度制限はない。

公式出典：2024年環境取得 run [42328567038](https://github.com/zuizui0223/mois/actions/runs/42328567038) SUCCESS、原2024数値CSV 66,456 GSHHG既知陸域target、うち43,595がVIIRS品質とGlobal2人口の双方を満たす。2024年の元写真151,355枚。**解析対象の選択は別段階**であり、光害の全66,456環境ターゲットが花色計測を持つとは言わない。

## 元写真・種レベルの集計方法

- 撮影年2024、元取得系列 \`historical_main\` のみ。別系列・園芸由来の未知の比率を無条件に混ぜない。
- 写真ID・観察ID一意（元source canonical計1,032,882）、成功済みstrict9の連続 \`strict9_white\` 数値のみ使用。technical unknownを非白・白のどちらにも含めない。
- GSHHG同一0.05°セルに**2以上の陸塊**が入っている場合、セルIDだけでVIIRSターゲットを結合すると島と本土を混同するため、**そのセルは一旦除外**。該当する陸塊target行2,146件を分析対象から外した。写真ごとの真の陸塊を再照合しない段階で推測配分しない。
- WCVPへの一意な受理種IDのみを使用して、各セル内で同じ受理種の写真平均→受理種均等平均で元ROI白色成分を評価。これは白花「種の割合」ではなく、花被を人手確認した観測でもない。
- 元写真の適格セルゲート：元 \`historical_main\` の撮影試行数>=5、strict9成功>=3、WCVP受理種数>=3。セルごとの重みは等しい。気候変数BIO5、log(1+BIO12)、標高、log(1+写真試行数)を調整。

実際の原写真は同一陸塊への安全結合後105,441枚、元strict9成功42,522枚。写真ゲート適格2,100セル、同年VIIRS>=3有効月の2,091セル、さらに同年Global2人口が確認できる1,617セル。最後の1,617セルでは191個の5°地理ブロックを固定効果・cluster-robust t区間として用いた。別の効果量推定対象を無理に混ぜない。

## 推定結果（探索的・原因未特定）

\`log_light = log(1+VIIRS_raw_2024_4months_median)\` 1単位当たりの \`strict9_white\` ×100の差（percentage points）。この係数は花色の進化速度、植物の消滅、蛾媒の花色選択の因果効果ではない。

**全球の人口調整後の光害係数はゼロを含む**。島内の元ROI白色成分の**負の対応は探索的候補**として現れたが、独立島の数が17で少なく、撮影構成や先行モデル選択があるためp値を確証として扱わない。

## 2024年島 vs 本土の写真の構成（対象を狭めた写真セルのみ）

2024年のphoto-gate＋同年VIIRSが有効な**島211セル**は元strict9白色成分の種均等セル平均52.168%、**本土1,880セル**は45.852%。差 +6.316 percentage points は、採集強度・地域/分類構成・生息地の違いを調整していないので、島効果、白花種割合、島シンドロームの証明とはしない。

## Global2人口欠測の非ランダムな空間依存

VIIRSと写真がある2,091セルで、**2024 Global2人口が利用可能1,617セル**の夜間光中央値は**2.515**、欠測**474セル**では**0.470** nW/cm²/sr。島内は前者164セル、後者47セル。人口を調整したモデルは暗い場所を選択的に除くため、「全陸域」の代表係数とは言えない。Global2のラスタ欠測を人口ゼロとして補完しない。人口欠測セルを除去したモデルを2020年Global1人口結果と同じ母集団・同じ版の比較として扱わない。

## 島内負関連の頑健性（実測の島のみ、仮想missingness設定はしない）

島内で人口・VIIRSの両方が利用でき、同じ島に光量の異なる2以上セルがある**17島×142セル**。島FE、2024人口、気候/標高、撮影努力で上記 −4.884。島を一つずつ除くLOIO17回ではすべて負（係数 −5.590〜−3.411）、**16/17回は名目95%区間がゼロを含まず、1/17回は含む**。その1島はland_id \`20\`、21セルを占める。元の標準誤差も17島しかないため不確実。

島単位のsource-only cluster bootstrapを**seed 20261107、1500回**行うと、係数のpercentile 95%区間**[−7.164, +0.0248]**で、**ゼロをわずかに含んだ**。97.4%の再標本化で負だが、再標本化の不確実性を無視して「夜間光で白花が減る」とは主張しない。

同じ142セルから人口を外したモデルでも島内係数 −3.627 [−6.240,−1.014]（名目p=.00956）。ただし人口が元々利用できる142セルを維持しているため、暗い人口欠測地を取り戻した結果ではない。**人口欠測の島を加えると20島×185セル、人口なし島FE β=−2.589 [−5.225,+0.0466]、名目p=.0538**と区間はゼロに接する。探索結果がsource selectionに依存する兆候。

同じ島内で2024年の異なる場所2セル以上から写真がある**同じaccepted species**は79種・83種×島グループ（186種×セル行、7島）。同じ種の固定効果・人口/気候/努力込みの探索係数は−10.169 pp/log、名目cluster7島区間[−20.293,−0.045]（p=.049）。しかし、個々の種×島74比較のうち負42（57%、両側binomial p=.295）で独立符号傾向は確認できず、**7島のcluster調整は弱い**。同種で色成分が変わる可能性には写真照明/器官/季節差もある。これは植生構成変化だけに原因を限定できないという診断であり、適応や機構の肯定結果ではない。
