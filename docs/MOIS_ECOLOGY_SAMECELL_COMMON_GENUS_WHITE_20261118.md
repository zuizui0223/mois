# MOIS：在来・導入植物相の花色差は、共通属だけで残るか？（2026-11-18）

## 現在地・重要な結論

**在来と導入の両群に同じ100km GBIFセルで現れる属だけに限定しても、写真由来の白ラベル種割合は、セル等重みではintroduced群の方が高い。一方、在来・導入の少数群の種数でセルに重みを掛けると、この共通属内の差は0付近になる。**

したがって「native/introduced差は非共有属だけによる」という断定も、「同一属なら一貫して導入種群の方が白い」という断定も不適切。**地理セルの代表のさせ方と種プール規模に依存する現在の種組成差**が直接支持される。

本モデルの白色はMOIS種別の写真9色modal proxyであり、花弁の個別独立確認を終えた形質ではない。native/introducedはKew WCVPの広域TDWG3分類で、個体の野生状態や人為導入の因果効果ではない。

## 1. 真正GBIF同一セル・同じ属の厳格比較

元の真正データは**37,104受容種、5,493,931種×100km格子**。先行するWCVP native-introducedの同一セル比較のstrict 3,106セル・moderate 3,602セルに、以前既に構築した真正GBIF種別×属の共通属表を、実際の `grid_x, grid_y` で連結。

**共通属を5属以上持ち、その共通属に属するnative種・introduced種がそれぞれ10種以上**ある、strict **2,516セル（421個の500kmブロック）**とmoderate **2,926セル（459ブロック）**を主分析に採用。旧真正共通属解析のセル数・元CSVの全セル数・写真白率の和を入力署名で確認。より厳しい共通属10属以上でもstrict 2,320、moderate 2,697セルで検証。

| 同じセルのnative−introduced写真白種割合 | strict：セル等重み (pp, 95%区間) | strict：少数群種数によるセル重み (pp, 95%区間) |
|---|---|---|
| **全ての属の種** | **−2.727** [−3.484,−1.988] | **−1.300** [−2.194,−0.421] |
| **共通属だけ・各属等重み** | **−1.569** [−2.507,−0.658] | +0.140 [−0.779,+1.015] |
| 共通属だけ・各属の少数status種数で重み | −1.743 [−2.706,−0.822] | +0.223 [−0.687,+1.084] |
| 全属差 − 共通属等重み差（参考：異なる推定対象の差） | −1.158 [−2.214,−0.084] | −1.440 [−2.294,−0.554] |

区間は**500km空間ブロック復元抽出20,000回**。moderateでも、共通属セル等重み−1.601pp [−2.495,−0.746]、少数status種数でセル重み+0.088pp [−0.779,+0.904]。共通属10属以上に閾値を上げても、strictのセル等重み−1.460pp [−2.378,−0.550]、種数加重+0.249pp [−0.658,+1.115]。strictとmoderateは多くの実格子を共有するため独立再現ではない。

**対象セル内で、共通属に属する種の割合はnative側が平均13.69%、introduced側が平均32.03%**。すなわち、共通属だけで比較するモデルは元の全種プールとは異なる標本を見ている。全属と共通属の平均白率の差を、独占属が引き起こした厳密な因果寄与・加法分解と呼んではいけない。また共通属内でも比較種が異なり、同一植物種が白花に変化したという意味ではない。

## 2. 現代水分・NPP・LGMは、共通属の白率差に関係するか？

同じstrict 2,516セルに現在の降水・気温、23年平均NPP、木質AGB、NDVI、LGM気温/降水差、緯度、native/introducedの種数、共通属数、共通属のカバレッジを同時調整し、500km空間ブロック固定効果・クラスタ標準誤差を適用。ブロック内変化のないセルはモデルから除かれ、**2,424セル/329ブロック**で回帰した。

| strict 500kmセル等重み：環境1SDあたりのβ (pp) | 全属のnative−intro差 | **共通属等重みのnative−intro差** |
|---|---|---|
| 現在log降水量 | +0.245 (p=.552) | −0.435 (p=.566) |
| 現代NPP | −0.163 (p=.636) | +0.954 (p=.253) |
| LGM→現代温暖化幅 | **+2.262 (p=.00763)** | +0.132 (p=.906) |
| NDVI | +0.970 (p=.0289) | −0.533 (p=.544) |

**主目的である現代降水・NPPは、共通属の白率差に安定した条件付き関連を示さない**。特に、前回の全属・同じセルで見えていたLGM係数の正の関連は、今回の共通属だけの比較では再現しない。LGM係数は*現在分布地点の過去気候差*に対する探索的相関であり、化石・花粉で氷期レフュージアを推定した結果ではない。

同じ比較をセル内少数群種数で重み付けると、strictの全属LGM係数は+0.763pp (p=.287)、共通属−0.779pp (p=.413) と双方の95%区間が0を含む。1000kmブロック設定やmoderate地理条件で感度評価を実施。全種・属・地理への一律効果としては定着しない。

## 3. 種プールの規模・緯度による異質性（探索的）

少数status群のセル内種数100を境界として、同じstrictの共通属等重み白率差を500kmブロックbootstrapで比較。これはデータ概観後に固定した**探索的な層別解析**であって、新たな事前登録検証ではない。

| strictの共通属等重み白率差 | セル数 | native−intro (pp, 95%区間) |
|---|---:|---|
| 少数群の種数が100未満 | 1,219 | **−2.746** [−4.166,−1.348] |
| 少数群の種数が100以上 | 1,297 | −0.463 [−1.388,+0.400] |
| 100以上 − 100未満（両層を同時bootstrap） | 全2,516 | **+2.283** [+0.806,+3.762] |

moderateでも高群と低群の差+2.246pp [+.855,+3.629]。緯度で絶対値30°未満／以上へ分けた共通属白率差の**差分はstrict −0.010pp [−1.929,+1.962]**で、緯度帯そのものによる二分は有力な説明にならない。

しかし、数値的な関連を**種プール規模の独立した生態機構**とは呼ばない。post hocの多変量感度では、同じstrict 500kmの「log少数status群種数」の共通属等重み白率差への係数は −1.382pp/SD [−4.818,+2.054], p=.430。現代気候・LGM・NPP・NDVI・AGB・緯度・属の共有率・属数・native/intro種数比を同時調整すると、有意な独立関係は確認できない。層別差の符号とこの条件付き回帰係数は推定対象・調整条件が異なるため、同一の因果関係として解釈しない。

今回の実証は、**導入種群の白色過剰が、一部の比較的小さな地域種プールに集中して観測され、豊富な種プールの代表性を重視すると弱まる**という、花色に関する組成記述である。

## 4. 何を主張できるか・次に測るべき生態学

支持するのは「**全球の白写真色ラベルの地理的差は、元のnative/introduced種プールと分類群組成が非一様であるため、地域の種数や共通する属をそろえた比較で大きく変化する**」。同一格子全属で差があることと、同属限定では重み依存になることの両方を必ず報告する。

否定していないもの：人為導入過程による種の選別、元の地域からの dispersal、送粉者ギルド、観測努力／写真ROI差が実際に関与するか。これらの機構は現時点で独立に識別できていない。**写真の白/非白proxyであり、植物学的に確認した花被色ではない。** 現代GBIF記録は野生の個体数・送粉成功・花弁色の選択係数ではない。

次の研究上の主要検証は、属と観測努力を調整した**生物地理区別のnative/introduced植物相**で共通属効果が地理的にどの程度変わるか、あるいは同属の導入可能性がどのように選択されるかを、検出モデルの多重探索を避けて独立に指定すること。現在の共通属テストは1つの連続した生態学的ストーリーとしてPR #205に統合する。
