# MOIS：既存40万色データの欠測種を補う最小64枚・実画像取得（2026-10-26）

## 実行結論

**SHA付き元93,209,351写真IDのうち、元候補写真が100枚以上あるが厳格ROI9がまだ0枚の分類群から、未測定64枚・64観察ID・64種を実際に選定し、元iNaturalist Open Data S3の500px画像を** **64/64枚**実際に取得・画素解析した。**

既存104万枚に写真IDと観察IDの重複0。地理×既存試行回数の8層で各8枚を**撮影画像を開く前**に固定した（北半球温帯側、南半球温帯側、北熱帯、南熱帯 × これまで1枚のみ試行/2–4枚試行）。全64画像の取得・デコード成功、YOLO flower-box候補64/64、sRGB→CIELAB花検出**生矩形BOX**色計測64/64、画像読込エラー0。画像本体の再配布0。画像S3アクセス上限2req/s、単一モデル読み込みで実施。

**重要：この64件は花弁真値でも、厳格な9成分ROIの追加成功64枚でもない**。新規写真にはROI-v4の高解像度flower foreground/EfficientSAMを適用していないので、過去の厳格9成分400,710枚と同一の品質や測定定義とは扱わない。現在の厳格9成分主解析母数は400,710枚のまま。104万旧写真と新64の写真ID集合は合計1,043,994、ただし撮影・色測定器が異なるためそのまま合算して一つの同質な研究応答にはしない。

## 選択バイアスを減らすために固定した設計

1. 元フル写真源を色に依存せず分離したtier07（観察ハッシュ条件付き確率幅0.0128）全16グループ・1,193,829元写真候補IDをSHAで全件再照合。
2. 2026-10-26時点で現存厳格ROI9がゼロ、元源で写真機会数100枚以上、以前に写真を**1–4枚だけ**処理した分類群4,368を候補。
3. 既存104万枚のPHOTO IDおよび既存OBSERVATION IDを全て重複排除。tier07内の候補観察3,434、候補種2,370。
4. 北/南・熱帯/温帯側×既存試行1枚または2–4枚の8層でそれぞれ8種類・8異観察を**色の観測前にSHA順位で選択**。64種、64写真、64元観察。その他の候補も元93m母集団から除外していない。
5. 元sample ledgerに各層の母数、種の条件付き抽出率、種内新規観察の抽出率、元源tier確率を保存。**この標本は過去のROI失敗で選んだ意図的補完デザイン**なので、これらを単純積算して全93mの無条件写真抽出確率・全開花植物の率・在来率と称しない。

## 現時点の判断

今回、正しい取得標本選定を守ったまま、南半球・熱帯の従来9色データ欠測種から本当に新しい画像を取得・RGB-Lab一次測定できることを確認した。**まだ最終的な植物花色を64種分得たとは言わない**。YOLO低閾値候補64/64は実際の開花・花弁正解を検証していない。BOX単独優占色の平均占有率が低いことと、緑や褐色に見えるBOX画素の存在は、花前景分離の品質評価が必要であることを示す。

次工程は、この64件の一部を、種名・地理・BOX色を伏せた目視で「花/葉/背景混入」を監査するか、同じ64元PHOTO IDに凍結flower foreground ROI-v4を走らせて9成分成功状態を追加記録すること。写真源は変えず、既存64件を再活用する。**9,320万件へ新たな無差別ダウンロードをこの結果を根拠に開始しない。**
