# MOIS 2026-11-16：全球37,104受容種の写真9色 × 水分環境・NDVI・木質バイオマス（複数モデルで独立検証）

## 現在地と推論上の結論

2026年11月1日公開GBIF 10,346 Parquet（合計約38.9億出現記録）から、COL XR 37,104種の真正なGBIF種×100km格子を取得済み。実際のWorldClim v2.1 BIO1〜BIO19＋月別降水・平均気温・日射・風速・水蒸気圧・VPD、MODIS-derived NDVI 2001〜2021年、ESA Biomass CCI v7木質地上部バイオマス2010・2020・2024年を同じ種に結合した。**36,753種・6,576属**で完全に比較可能。学習単位は「受容植物種1行」、GBIF分布格子を独立した写真のように複製して学習しない。

**結果**：RFの群ごとの検証標本置換重要度では水分環境群が最上位だが、**その群を除いて再学習するとAUCが低下せず、むしろわずかに改善する**。つまり水分情報は他の気候変数と共有されており、「水分が花色を決定する独立主因」と結論できない。木質バイオマスの増分予測は極めて小さい。別モデルによる検証でも原因を断定する根拠はない。

## 機械学習での最重要「予測因子群」は一致するか？

| 属を分離した予測モデル | 白 vs 8色 ROC-AUC |
|---|---:|
| Random Forest：全環境群 | **0.55581** |
| RF：AGB群を除去 | 0.55489 |
| RF：水分・湿度・VPD群を除去 | **0.55726** |
| RF：NDVI群を除去 | 0.55474 |
| HistogramGradientBoosting：全環境群 | **0.56164** |
| HGB：AGB群を除去 | 0.56244 |
| HGB：水分群を除去 | 0.56122 |
| L2 LogisticRegression：全環境群 | 0.55749 |

RF fullからの**各群を一括で検証データ上入れ替える置換AUC低下**（3 fold、各3回perm、合計9回の平均）は：水分・湿度・VPD **0.03056**、気温 **0.00595**、風速 **0.00192**、NDVI **0.00079**、日射 **0.00028**、木質AGB **−0.00028**。しかし、RFの水分群を除いて再学習するとAUCは0.00145上昇。モデルの水分への依存性と独立情報量は**別物**。気候群間の多重共線性・代理変数があるため、重要度を花色の因果選択圧と同一視しない。

9分類RF balanced accuracyは全環境0.16307、**木質AGBを除外しても0.16297**、水分群を除外すると0.15868。ランダムな9色の均等予測基準は約0.111だが、写真9色の属外予測は全体として低い。

## RF以外：属内の多変量モデルによる条件付き検証

同属内に白・非白写真色が共存する**2,376属・29,541種**の各環境変数を属平均で中心化し、花色の0/1を応答とする線形確率モデルを属クラスタ共分散で検証した。気温、降水・湿度・VPD、日射、風、NDVI、木質AGBを**同じモデルに同時投入**（GBIF記録数・緯度・写真色statusも調整）。各群のjoint Wald、6群BH多重検定。

| 環境変数群（属内・同時調整） | p | q（6群BH） |
|---|---:|---:|
| 気温群 | **0.00559** | **0.03356** |
| 木質AGB量＋木質植生被覆＋2010–2020年変化 | 0.01845 | **0.05155** |
| 風速 | 0.02578 | 0.05155 |
| 日射 | 0.07077 | 0.10615 |
| 降水・湿度・VPD | 0.09665 | 0.11598 |
| NDVI | 0.36102 | 0.36102 |

**属内の同時調整では気温群のみBH q<0.05**。これはRFの水分群置換順位と異なる。線形モデルの形・共線性・検証標本内での因果推定限界があるので、「気温こそ決定要因」とも言えない。木質AGB群も6群補正ではq=0.05155で境界的、独立した生物学的因子としての確証ではない。単独2020年AGB係数は1SD当たりwhite写真確率−0.0133（p=0.188）、森林被覆1SDでは−0.0136（未補正p=0.0463）。

## バイオマス自体との直接的な関係

写真色によるAGB2020の単純中央値：白20,732種 **43.384 Mg/ha**、非白16,021種 **37.298 Mg/ha**。種のGBIF記録先の*周辺木質植生*を平均した値であって、花色植物個体の乾燥重量ではない。

同属の白・非白が両方ある2,376属・29,541種、年平均気温、年降水、NDVI、平均絶対緯度、GBIF記録数、写真evidence statusを同時調整したところ：
- 2020年木質AGB量のlog(1+Mg/ha)：白の係数 **−0.01531（95%CI −0.02866〜−0.00197, p=0.0245）**。
- 属を等重みにした同じ関係：**−0.00564（95%CI −0.02229〜0.01102, p=0.5071）**。安定した量の差とは扱えない。
- 木質植生のAGB>0地点の割合を属等重みで見ると白の差 **−0.00547（95%CI −0.00956〜−0.00137, p=0.00895）**、約−0.55パーセントポイントという小さい差。多数の候補指標から事後探索したため、このpを単独の確証とは呼ばない。
- 種の平均NDVIと平均AGBのSpearman rho **0.87081**。NDVIとバイオマスは情報が重複し、RFでの片方の低い重要度は生態的な無関係の証明にならない。

色別の2020年周辺木質バイオマス中央値（Mg/ha）：blue39.1、bronze38.4、magenta34.5、orange45.2、pink38.8、purple35.1、red48.5、white43.4、yellow34.9。ただし9色間の不均等な受容種数、系統・在来性・面積・撮影検出誤差により順位を生態的な優劣と解釈しない。

## さらに重要な研究上の制約と次の焦点

- 入力の花色はiNaturalist画像モデルの**写真modal9色**であり、GBIF出現セルの花被・花色実測ではない。以前の真正マスク点検5枚中4枚は葉・背景・端部を誤検出した。全球受容37,104種すべての花被色が正解と保証されていない。
- ESA CCI AGBは衛星SAR由来の**木質植生量**、草地・草本花生物量や送粉者の餌資源・花への投資の指標ではない。近傍林の多さが種固有の花色を作ると解釈しない。
- GBIF記録は自生・外来・栽培を区別できていない。1970–2000年のWorldClim気候と2001–2021年NDVI・2020年木質AGB、2026年公開GBIFの観測日とは年代が一致しない。観測努力・系統・分布範囲と地域の交絡も残る。
- **暫定結論**：群置換で水分環境がRF最上位、独立群除去では有意な増分なし、属内線形モデルでは気温群が最も条件付きで関連。木質AGBも、白色を説明する強い独立予測因子とは示されない。単一の「最も決定的な環境要因」を確定するには**色ROI正解検証と地域・在来種フィルター、系統制御、外部独立データでの一致**が必要。
