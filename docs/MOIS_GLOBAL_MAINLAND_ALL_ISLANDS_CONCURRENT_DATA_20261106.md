## 対象範囲を修正

ユーザー指定に従い、MOISの主対象は**大陸と島を含む全球**とする。`island`リポジトリの島限定・面積5 km²という運用条件はMOISの取得対象に持ち込まない。島面積は説明変数・記述情報であり、取得の除外基準ではない。北緯60度以北・南緯60度以南も取得枠から落とさない。水域・海岸線・地理判定未確定・座標欠測・技術的色判定不能を、非白花または大陸へ変換しない。

新しい取得コードは `scripts/acquisition/mois_global_acquisition_20261106.py`。方針は `config/mois_global_land_scope_20261106.json` に保存した。以前の5 km²以上を対象にした島分析は履歴として残すが、新しい取得母集団の定義には使用しない。`island`リポジトリ自体は変更しない。
