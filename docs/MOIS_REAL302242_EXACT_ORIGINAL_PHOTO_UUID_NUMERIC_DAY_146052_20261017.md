# MOIS original 302,242 image pixels: close the remaining 4,096 UUID-date hole using the authentic full FCP source

**Date:** 17 October 2026. This is the real worldwide among-taxon photographed floral-hue and local-season MOIS paper source, not the FCP separate within-species D/W/50-km phenotype polymorphism dataset.

## Why this is a source-data repair rather than a photographic prediction

The previous [signed 302,242 original photo-pixel source](https://github.com/zuizui0223/mois/actions/runs/39018960100) had **146,061** original four-hue classifier outcomes but only **143,770** with a valid original or independently photo-ID-verified public observation day. The missing calendar-day population has two very different original observation-identity types: **1,751** photo IDs whose exact original iNaturalist `observation_id` is numeric and **4,096** source-selected early ROI photos whose original `observation_id` is UUID. It would be incorrect to simply submit the UUID values to the numeric observation API, just as it would be wrong to use modelled WorldClim monthly normals as camera timestamps.

[Source-verified 36-call original iNaturalist numeric observation API run #39019305535](https://github.com/zuizui0223/mois/actions/runs/39019305535) has already recovered current valid observed-on days for **1,732 of those 1,751** original photos, with literal original photo ID membership inside the correct numeric source observation. **706** already actually classified four-hue photo ROI outcomes gain observation days; 19 source numeric IDs remain unresolved. All previous 99,817 historical S3/API current public observation dates and original source photo pixels/hues are unchanged.

Crucially, the **genuine original FCP all-photo-ID source** preserved not only 106,376 outcome-blind photo-screen IDs but the complete **3,430,502 underlying selected original photo metadata records**. The screen-level 106,376-photo convenience table omits `observed_on`, **but the original full metadata** file `rgfca_1000_complete_original_source_photo_IDs.csv` retains original photo ID, observation UUID, taxon ID, true public `observed_on`, coordinates and original September 2026 source snapshot. This is a distinct, provider-signed restoration route which does not require any new iNaturalist API call or photon pixel download.

## How much ecological season source support becomes possible?

With both kinds of original observation identifiers finally qualified by independent source metadata, the colour/observation day intersection is almost complete. The extra-tropical white-photo seasonal fractions can be compared with the prior 143,770-date-hue state and evaluated at *fixed 0.25° original coarse locality cells and meteorological season-year*, requiring at least 5 distinct original photo observation IDs and 2 distinct source taxa per summer and winter. Photo-level date closure increases the source comparison denominator, but the same **named taxon × fine geographic cell × same season-year** repeated observations remain biologically sparse and source-structured. Full-source 999 geographic-cell-cluster bootstrap percentiles must not be treated as experimental or multiple-choice-adjusted evidence of pigment plasticity.

Even 146,052 colour-and-day photographic ROIs **do not imply 146,052 botanically verified open flower petals**: the classifier may include other plant organs, the iNaturalist current photo/source day may differ from independent camera EXIF, photo visitation/observer effort is unmeasured, and photographs missing from a season are not evidence that a taxon lacked flowers. The [integrated MOIS paper](MOIS_GLOBAL_FLORAL_COLOUR_MOISTURE_AND_SEASONAL_SAMPLING_MANUSCRIPT_20261017.md) must keep the 999-genus *annual long-term climatic-normal* white-versus-moisture model and this *seasonal photographed flora* photo-composition investigation as different observational estimands. Seasonal *observed-year* temperature/radiation/VPD/moisture data and photo-specific anthesis remain future independent evidence.

**No results from the planned 3.43 million original-photo-ID opportunities are silently counted as measured ROI labels.** Only **302,242** source photos had real pixel classifications attempted; **146,061** have a genuine four-hue outcome and, after exact date rejoin, **146,052** of these have source-dated original observations. The remaining opportunity images were neither treated as classifiable nor flowers.
