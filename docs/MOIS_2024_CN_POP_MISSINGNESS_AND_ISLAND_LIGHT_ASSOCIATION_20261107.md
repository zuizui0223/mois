# MOIS 2024全球の夜間光・花色と人口欠測の実測診断（2026-11-07）

## 主線と原数値

MOISは島だけでなく全球本土・全島を解析対象とする。面積5 km²／緯度±60°で島や本土を除外しない。原写真を再取得したり、技術的unknownを白・非白に補完したりしない。元写真をそのまま0.05°セル×GSHHG陸塊へ接続し、受理種を均等に扱った2024年の写真上の連続白色ROI成分と夜間光の**対応**を検証している。

[2024年全66,456既知陸域の実数値取得run 42328567038](https://github.com/zuizui0223/mois/actions/runs/42328567038) **SUCCESS**。元canonical/2024 source 69,196セルのうち島8,908／大陸57,548の66,456地点を同年2024年の月次VIIRSとWorldPop Global2 **R2025A v1 constrained** 1km人口グリッドに結合。原photo GSHHG SHA256 \`f7f65e6bc167089b3034555c655e777f528ecdd29952ab7ee9833d8722f39267\`、全66,456実測CSV SHA256 \`6e0a077d496e90848d05d043bffae57e4772519f4572a457221c5ef4da0fb813\`。人口GeoTIFFは単位「人数／ピクセル」であり、WGS84測地面積で割り「人／km²」に変換（元GeoTIFF SHA256 \`3539cbac76092c1e8c8d45426fc0dfb06067a1e3f28bfbee993dba21aa03194e\`）。

- VIIRSの1/4/7/10月のうち3か月以上が有効：**64,646／66,456地点**。
- R2025Aの人口値が有効：**44,667／66,456地点**。
- **両方のソースが揃う：43,595地点**（島5,784、大陸37,811）。
- **人口ソースが未取得／NoData／範囲外：21,789地点**。そのうち**21,051地点はVIIRSの必要月数を満たす**。
- 人口ソースがない地点には元strict9成功画像**16,696枚**がある（うちVIIRS3か月以上の地点では**16,285枚**）。これは新しい画像計測枚数ではなく、人口不足で解析から除外されうる**既存計測結果**の数である。
- 夜間光中央値：人口ソースあり **1.070**、人口ソースなし **0.425**。差があるため、人口を共変量にしたモデルだけを選ぶと暗い地点が相対的に失われる可能性。源ラスタの「RASTER_OUTSIDE_OR_NODATA」は原因を個別に分離していないため、欠測全件を都市化ゼロや人間活動ゼロに置換しない。
- 島面積5 km²未満の**214セル**も保持。うち人口値は173セル、VIIRS＋人口の両方が159セル。
- 出典を持つ写真は2024年元系列の既存写真のみに限定。新規原写真取得・strict9再推論・MNAR tipping解析を行っていない。

## 原解析の結果と解釈範囲

[同年2024全球＋島内解析run 42332914852](https://github.com/zuizui0223/mois/actions/runs/42332914852) **SUCCESS**（前run 42329952148と出力数値一致）。元の\`historical_main\`、WCVP受理種・厳格ROI9・元写真で少なくとも3種のセル、同年VIIRSを結合し、色成分の平均を種・セル均等で算出した。

- 2024年VIIRSと写真2,091セル。地域など調整後の全球係数：**−1.00 pp/log(1＋光量)**、95%区間 −2.07〜+0.07。
- 2024年人口もある1,617セルの全球人口調整モデル：**−1.05**、95%区間 −2.80〜+0.69。
- **島内固定効果17島・142セル**：人口、気候、標高、写真機会を調整した同島内光量係数 **−4.88 pp/log(1＋光量)**、名目95%区間 −8.30〜−1.47。
- 島を単位にした1,500回の再標本化では95%区間 **−7.16〜+0.02**、ゼロを含み、符号が負の反復は97.4%。島1つずつ除外では17/17負だが、1島を除くとその95%区間がゼロを含む。**探索的な負の対応**を越える一般化はしない。
- 島×光量と大陸×光量の交互作用：**−2.77**、名目95%区間 −6.23〜+0.70、p≈0.117。**島の効果が大陸と有意に違うとはまだ言えない**。
- 花色データは写真の連続白色ROI成分で、独立の植物学的白花種率ではない。蛾の実効夜間送粉、種の地域からの消失、光害の因果効果は未測定。

## 今実行している次のデータ取得

2024年の人口欠測を調べるため、公式別製品 **WorldPop R2024B v1 unconstrained** 2024年全球GeoTIFF約868MBを原本取得する。これはR2025A v1 constrainedとは**異なる人口推定モデル・異なるリリース**であり、欠測地点だけをR2024Bで埋めて一つの共変量にしてはいけない。2024年既知陸域**全66,456地点**をR2024Bの同じソースで再抽出して別系列として保持する。[Source-probe run 42333517761](https://github.com/zuizui0223/mois/actions/runs/42333517761) SUCCESS: 公式R2024B UC 2024のGeoTIFF・HTTP 200と完全長868,021,365 bytesを確認。範囲要求はサーバ側で無視されたため本番では全文を一度取得しSHAを計算。別ソースの新規実測完了まではR2024Bで人口がどれだけ回復すると推測しない。

画像・出典の補完済み数を機械的に加算せず、端末上のキャッシュとSHAを維持する。PR #199はDraft、main未変更。
