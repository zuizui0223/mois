**最終行は支持例として採用しない。** 25属95種のうち有色50種の47種が黄。古気候・地域・種分布幅等の共変量を十分にそろえられておらず、写真花被色自体も未確認。単一の色仮説を事前固定していない探索的な複数部分集合比較でもある。属再標本化の95%区間がゼロを含まない（+0.094～+0.936）一方、帰無ラベル置換p=.0555であり、手法の仮定の違いに敏感。いずれか一方だけを拾って「有意な白花史的適応」と表現しない。

既存の**属固定効果＋気候幅・中心・在来格子数・候補地域数・写真品質調整**では、全6,866種/822属の種均等係数 **−0.01450**（属クラスタ95%CI [−0.06169,+0.03269], p=.547）、属均等係数 **+0.03189**（[−0.03795,+0.10173], p=.371）。結果の方向が重みで変わる。上の新しいラベル置換は**この共変量調整モデルを再現する検定ではない**ので直接比較して一つのp値にまとめない。

### 研究実務上の意思決定

1. MOISの主張は**写真由来９色の現代種組成と気候履歴の記述**に限定する。現時点でLGMレフュジア・白花の氷期適応を結論しない。
2. ９色クラスを増やすなら、元写真の真正花被ROIを人手・器官抽出で独立検証し、色品質レベルと生物種内多型を保持する。全色を暫定単色に強制統合しない。
3. 歴史的生存については外部古生物記録が必須。Neotoma公式API（https://api.neotomadb.org/）の試行を独立工程とし、年代付き種レベルの大型化石と属レベル花粉を区別。**花粉の属一致をその種の氷期存続証拠にしない**。
4. 各証拠を「種×時期×場所×同定水準×年代誤差」に分け、外部独立記録とGBIF/写真由来の情報を混同しない。
