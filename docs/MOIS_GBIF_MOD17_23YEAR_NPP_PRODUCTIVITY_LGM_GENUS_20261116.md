# MOIS｜真正GBIF全球格子 × MOD17 23年年間NPP × WCVP科固定属プール（2026-11-16）


> **2026-11-17：主目的の再固定 — 花色を応答変数へ戻した実解析を完了**。[種別白／有色および探索的9色×GBIF分布域NPP・木質AGB・NDVI・LGM履歴、さらに在来植物相での属構成分解](MOIS_PRIMARY_FLOWER_COLOUR_GBIF_NPP_LGM_20261117.md)。本資料の属Jaccard・科固定帰無モデルは、花色と環境の関係を評価するための**分類群構成交絡の診断**として位置付ける。写真は花色proxy、GBIFは現代の種分布、LGMは現在分布地点の過去気候であり、氷期レフュージアを再構築したわけではない。

## 結論・現在地

**2001–2023年の年間NPP真正公開原本を取得し、GBIF 18,577格子に23年間を完全接続した。NPP追加後の解析も実行成功。**

注目すべき生態学的な結果は、**NPPが高い地域ほど、現在のGBIF自生・外来植物相の共有属率（観測Jaccard）は低い**という関連が、現在気候・LGM気候変化・木質AGB・NDVI・観測記録数・分類群数・500km地域固定効果を調整しても現れること。

ただし、**科構成、native/introducedそれぞれの種数、属ごとの種数を固定した帰無期待Jaccardにも同じ負の関連があり、観測−帰無期待の残差にはNPPの独立した関連が確認できない**。生産力が定着を直接選択した、氷期レフュージアが花色を決めた、とは言えない。今回の**目的変数はGBIFとWCVP由来の属のJaccardであり、花色写真由来ではない**。

残差へのNPP増分のモデル内R²はstrict **+0.0000460**、moderate **+0.0000274**。**これはholdout予測性能ではない。** 全23年完全格子のみ、NPP単年2020、500→1,000 kmブロック、格子内記録種数重み、AGB・NDVI除外などの感度比較でも、科固定残差に対するNPP係数に頑健な有意性は確認できない（strict単年2020 p=0.939、全23年p=0.487、1,000km p=0.275、種数加重p=0.367。moderate単年2020 p=0.499、全23年p=0.900、1,000km p=0.116、加重p=0.979）。

## 生態学的解釈と残る制約

1. **支持される記述：** 現在GBIF記録種プールでは、年間NPPと自生／外来属の重複率に負の対応がある。科ごとの種数と属内種数を保存した帰無期待の変化と、その傾向はほぼ重なる。自生／外来の属分離は現在の群集組成の非ランダム性としては明瞭。
2. **未支持：** NPP自体が科固定帰無を超える独立した属分離を説明すること。木質AGB・NDVI・LGM気温履歴の強い独立効果。花色選択、外来定着フィルター、氷期レフュージアの因果的推定。
3. **重要な観測上の限界：** GBIFは出現観察の記録数（努力量）で、植生の種相対個体数・優占量を測っていない。WCVP `native_at_TDWG3` は広域の在来分布属性で、野生個体・個別島の自生を認証していない。対象37,104種はMOISで名前が対応したカタログ種集合で全球全植物群集の無作為標本ではない。
4. **尺度と時間の限界：** NPP原本は0.5°への再格子化データ（2001–2023）、AGB2020、NDVI2001–2021、WorldClim現在1960–1990、LGM約22kaと期間が異なる。NPPは**kg C m−2 yr−1 のフラックス**であり、Mg dry woody biomass ha−1のAGB（ストック）や花弁色素生産・繁殖投資とは別。

## 次段

「NPPの独立した非ランダム属分離効果」は主張しない。主線を進めるなら、将来の*真のレフュージア分布復元*には独立した古生物地理資料（花粉・化石・氷床履歴・系統地理）を接続する。同時にGBIFの在来・人為・栽培記録の区別や生物地理区間の差を検証する。今得たNPPの23年セル系列は再取得せず、別解析ではSHA固定の成果物を再利用する。
