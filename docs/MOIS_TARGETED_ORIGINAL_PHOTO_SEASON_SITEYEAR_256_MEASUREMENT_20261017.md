# MOIS real data growth designed to identify same-taxon photographed summer–winter comparisons

**Study objective:** Rather than adding another random/cross-taxonomic 4,096 original images that rarely revisit a taxon/site/year, select additional source photographs that are genuinely *likely to add an independent photo observation in a season currently under-represented* in the original photo source. Do not preselect new photos by their unseen colour. The outcome is still an **automatic photographic ROI hue** and must not be interpreted as verified open petals or causal pigment plasticity.

## Explicit original source identity and before-pixel conditions

The source-verified [MOIS full original measured photos](https://github.com/zuizui0223/mois/actions/runs/39028400690) contain **309,439** actual pixel-processed photographic ID attempts, **149,662** four-hue ROI results and **149,653** dated/classified original photos. Their compressed source photo/date table SHA256 is `546266e2bbaa340a2523864c28c5a877842eb4b0904a7e0dff90870c6519a47e`. Among actually dated and *four-hue-classifiable* photographs, only **74 named-taxon × 0.25° lat/lon cell × local meteorological season-year source groups** have at least one distinct original observation in both local summer and winter; just **two** groups satisfy two observations in each season. Those are source-photographic, not individual biological populations; many original named taxa have only one source-photo observation.

The [full iNaturalist/FCP original 27 September 2026 source](https://github.com/zuizui0223/fcp/actions/runs/38884223530) includes **3,430,502 source-photo ID/date/location opportunities** in **1,000 source taxa**. It is not 3.43 million independently verified flowering photographs. The separate [fourth-wave MOIS pixel processing PR #55](https://github.com/zuizui0223/mois/pull/55) has already frozen **4,096 other never-before-measured original photo IDs**, with original deterministic source-selection CSV SHA256 `65fc139909f94448e042b6539c6749e70d1ab21bb8b13f50383bb7417180337a`. Those source IDs are excluded here **even if no original RGB pixels have yet completed**. Thus different measurement workflows cannot count the same future photo twice.

## Target source sampling (prospective and outcome-blind for the newly selected photos)

`scripts/analysis/mois_target_season_cell_original_photo_source_only_20261017.py` starts with the signed 309,439 original photo/color/date cohort and counts original observations by **original named taxon × 0.25° cell × meteorological season-year × actual hemisphere summer/winter**. It uses existing photo **classifiability presence**, never the white/chromatic response values, to identify where source observations are sparse. Decembers are assigned the following local season-year; seasons reverse in the Southern hemisphere and tropical observations do not enter the target comparators.

After excluding every existing pixel-measured source photo and all **4,096 separately reserved fourth-wave photos**, it scans the entire original 3,430,502-photo FCP metadata population. It checks original numeric photograph/taxon IDs, source photo URL and public-license pattern, taxon, latitude/longitude, observer/observation identifiers, authentic `observed_on` and the literal 2026-09-27 source snapshot. Source-candidate selection priority is:

1. A photograph taken in a season for which a *same named taxon × cell × season-year* already has an opposite-season source photo but lacks two distinct observation IDs in the candidate season.
2. A photograph that could fill a currently missing opposite season for a photographed taxon/cell/year.
3. A photograph that increases within-cell/year observation depth in a season already sampled.
4. A separate photo-ID-hashed taxon-balanced fallback if too few local matching opportunities exist.

The source-only selection hash uses just each previously unseen **photo ID**, and the priority comes only from **where/when/what taxon was photographed** in already verified original sources. It never reads new image pixels or candidate photo hue. It retains **4,096 unique source photo IDs with distinct original observer and observation IDs**, spread across 16 frozen 256-photo shards. The first 256 source photos are deliberately chosen from highest-priority taxon×site×season-year gaps rather than random abundance data. The remaining 3,840 are *reserved source IDs only* and do not increase the scientific photo-pixel denominator until actually measured.

**Critical inference distinction:** This is explicitly targeted/enriched photographic recruitment and MUST NOT be pooled into the unweighted original genus-equal worldwide annual white/precipitation effect or treated as a representative summer/winter photo sample. Results may be used to diagnose the feasibility of local within-taxon photographic comparisons and to plan balanced prospective field sampling. A candidate future colour state cannot be inferred from source-photo metadata.

## Actually measured RGB pixels and positive-control QC

The finite [source-ID → genuine photo pixel → terminal colour → source join GitHub Actions workflow](../.github/workflows/mois-targeted-real256-original-photo-season-replication.yml) obtains all 256 first-shard photographic RGB images under source-appropriate licenses and runs the **identical previous MOIS/FCP YOLO11/EfficientSAM ROI-v4 method** with pinned detector/source/model SHA, four separate original 64-image terminal outputs and complete technical-unknown outcome accounting. The per-source shard terminal contains **actual** photographic hue classification (white / yellow-orange / red-pink / blue-purple / unknown), not photo-ID opportunities or generic plant labels. Only those 256 signed terminal photo IDs are appended to the original 309,439-photo source with the independently source-recorded day. Prior photo IDs/taxa/hues, the 99,817 verified historical observation date outcomes and all earlier source statistics remain untouched.

The final original photo/source-QC receipt reports 309,695 photo-pixel attempts upon successful source completion, the **actual** (not assumed) number of newly classified hues and observation dates, and actual changes in same-taxon × same 0.25° cell × local season-year summer/winter **≥1/≥2 original observations per season** (74/2 initial all-hemisphere source). An increase in repeated site/year photographed organ observations is **not itself** a response to weather, pigment cost/benefit or verified open-petal anthesis. Source annual WorldClim normals still are not observation-year/month meteorological data, and FCP D/W intraspecific genetic-spatial estimands are not imported.

No new photo/colour/sample-size conclusion is claimed until both independent source and pixel workers finish; the exact temporary photo-server original image bytes are not retained as GitHub artifacts.
