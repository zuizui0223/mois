## データ・推定単位

- 元写真ID：**350,399枚**（異なる撮影系列の重複を厳格に除去）。固定済みROI-v4による4色分類：**164,297枚**。それ以外の**186,102枚はunknownのまま**。
- 年間気候・大気中水蒸気・標高・5指標完備かつ4色分類済み：**163,905枚**。
- 世界の全93,209,351写真IDが分類されたわけではない。2026-10-25時点の最新画像取得**1,019,272枚／4色分類449,741枚**は存在するが、気候・島嶼・季節の同一粒度のデータ結合が全件で完了していないため本解析に勝手に足さない。
- 島嶼・大陸と近接高低差の比較では、既存のGSHHG高解像度海岸線を元に写真IDで地理照合できた**313,535枚、4色分類151,239枚**の固定部分集合を使用。
- 間接応答は「*写真に写る花らしい器官からアルゴリズムで割り当てた可視白花ラベル*」。花弁・開花・在来性・送粉者・色素・適応度は直接確認されていない。

## 1. 湿潤と乾燥の関係

元分類群×5°地域セルを等重みとした、年間降水量（対数）5分位の白色率は **44.76%、46.60%、46.98%、49.19%、51.86%** と湿潤側ほど高い。これは記述的で、撮影対象・分類群の構成差も含む。

属×地理セル×取得系列内、複数分類群支持を要求し、元の分類群セル全体に対する環境SD当たりの局所・単変量係数（白花パーセントポイント）：

| 予測因子 | 5°／属ブートストラップ95%区間 | 10°／同区間 |
|---|---|---|
| 年降水量 log(1+mm) | **+1.49** [−0.13, +3.05] | +0.69 [−0.86, +2.26] |
| 平均年間大気中水蒸気量 | **+5.03** [+2.56, +7.16] | **+4.60** [+2.36, +6.76] |

5°比較では **31,675分類群×セル** が解析対象で、2,000以上の属から環境差が得られた。大気中水蒸気の正の関連は5°と10°の両方で再現したが、年降水量は地域・属条件付け後にゼロを含んだ。温度・湿度・標高・日射の交絡は残るため、「水蒸気の因果効果」とは言わない。

## 2. 高標高

属×5°地域セル×系列の局所勾配：標高1 SD当たり白花 **−2.50 pp** [−3.84, −1.01]。10°では **−2.91 pp** [−4.27, −1.74]。

厳密に同一陸塊×近接5°地域で1°分類群均等セルを比較できた**44地域**では：

- 標高0–500m：白花 **46.30%**（191セル・16,144分類済み写真）
- 標高1,500m以上：白花 **41.22%**（109セル・8,425分類済み写真）
- 高地−低地：**−5.09 pp**、名目95%区間 **[−8.78, −1.39]**。44中31地域で高地側の白花率が低い。
- 10°の近接比較でも **−4.58 pp** [−8.98, −0.17]。

**マクロ生態学的な高地での有色花相対過剰**の候補。紫外線/温度/送粉者の適応機構、個体内の色素誘導とは区別する。

## 3. 島嶼性

313,535枚の元海岸線照合部分集合では、4色分類写真の白率は島50.933%、大陸46.710%（**島＋4.22 pp**）。島と大陸双方を含む同じ粗地理帯（1,394分類群均等セル）、年降水量・日射・暑熱・標高を調整した回帰では **島＋3.16 pp** [＋0.28,＋6.04]。

しかし環境・地理的共通支持を重視し、色ラベルを使わず気候条件から最適にペア組みした**102島—大陸セルペア／65島嶼陸塊／28地理帯**では **島＋1.40 pp** [−1.55,＋4.34]。名目p=0.34。

**島の白花過剰は比較対象・重み・環境重なりに依存し、普遍則ではない。** 島の送粉者減少・在来植物の白花化・単一の島嶼適応機構は未検証。

## 4. 季節

観察記録日からの気象学的夏（北JJA、南DJF）と冬（北DJF、南JJA）、亜熱帯/温帯側のみを比較。**各季節の撮影写真の種構成と撮影頻度を含む比率**であり、同一個体の花色変化ではない。

| 季節 | 北半球温帯外縁 | 南半球温帯外縁 |
|---|---:|---:|
| 夏に4色分類できた写真 | 47,282 | 7,796 |
| 冬に4色分類できた写真 | 5,077 | 5,409 |
| 夏−冬の白率 | **＋2.83 pp** | **＋10.50 pp** |
| 両季節で写真のある種の白率変動成分 | +3.26 | +3.57 |
| 共通種の相対的な撮影頻度変動成分 | −0.86 | **＋8.04** |
| 夏のみ写真がある種の寄与 | +2.92 | +4.16 |
| 冬のみ写真がある種の寄与 | −2.49 | −5.27 |

4項を合計すると各半球の実測差に厳密に一致する。南半球で特に**共通種の相対的撮影頻度**が大きな寄与を示した。異なる場所・撮影者・開花個体が混在するため、季節的な進化・生理的可塑性は識別できない。

## 4軸からの論文化方針

**世界の撮影植物群集における可視花色組成は水分状態・標高・地理・季節的な分類群組成の複数階層に対応するが、各関連の頑健性は異なる。**

大気中水蒸気量との正の関連、高標高での白花の減少は、ここで試した地理・属の感度分析で同じ方向を保った。一方、島嶼過剰は共通環境支持の比較で不確実、季節差は撮影種構成の変化に強く依存する。島の花が白色に適応した・乾燥が色素を直接増やした・季節で同一植物が変色した、という機構的主張はこのデータではできない。
