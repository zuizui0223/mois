# MOIS | 光害 × 島嶼 × 白色ROI：2019–2025の同年相関と5年統合（2026-11-07）

## 結論（実測解析、論文の結果候補）

全球写真標本における原画像ROI9の**白色連続成分**と夜間光量の関係について、島×光量の交互作用は2019・2021・2022・2023・2024・2025年の単年回帰ですべて負方向だった。2019/2021/2023/2024/2025の5年の同年WorldPop R2024B UC・VIIRSを用い、写真の元年、地理5°ブロックと年を調整した統合モデルでは **島×log(1+VIIRS) = −2.4970446 pp**、地理ブロックでclusterした名目95% CI **[−3.948547,−1.045542]**、名目p=**0.0008023**。解析対象は**7,982原写真セル×年**（うち島**710**）、地域ブロック**317**。

これは観測された花色ROI成分と夜間光の**空間的対応**である。白花「種」割合、地域植物相の真の多様性、ALANによる種消失、蛾の実効的送粉損失、色素の適応・因果応答は推定していない。探索的に複数モデルを検討した後の名目p値であり、多重性調整済みの事前固定的な確証ではない。

## 5年間統合：原本SHA・観測単位・空間/年依存

使用年は **2019, 2021, 2023, 2024, 2025**。**2022**は10月VIIRSのArcGIS raster 400で4月期が4か月揃わず、同一観測月の主統合モデルから外す。**2020**の元人口はGlobal1、他年はR2024B UCなので主統合モデルには混ぜない。既存の2020観測結果は消去せず別に保持。

- 対象源：canonical元 **1,032,882 photo/observation ID**、GSHHG 2.3.7、WCVP exact accepted taxon ID、元strict9実測ROI、同一年の月別VIIRS Jan/Apr/Jul/Octのうち3月以上の品質合格・同一年 WorldPop R2024B UC。2024年はCNからUCへの独立データ系列の差し替え、他年も同じUC版を指定。
- 花色応答：元 `historical_main` の写真を0.05°セルで、元写真試行>=5、元strict9成功>=3、unambiguous WCVP accepted種>=3。種内で白色ROI成分を平均→セル内で受理種を均等平均、さらにセル×年均等。technical unknownは白/非白に変換しない。
- 元0.05°セルが複数GSHHG陸塊を含む場合は誤った島/本土の結合を避けて除外。島の面積・緯度による取得足切りなし。元写真種・島・地理ブロックの繰返しを新規独立検証と扱わない。
- 統合式：`white_pp ~ log_light * is_island + log_pop + bio5 + log_rain + elevation + log_attempts + C(region5) + C(year)`。5°の同じ地理ブロックを年を越えて同一clusterとして扱う。
- 主結果：**−2.4970446**、SE **0.737740**、95% CI **[−3.948547,−1.045542]**、p **0.0008023**。元解析 run **42363637615 SUCCESS**。
- 44島の同島内（異なる2以上写真セル・異なる光量）を使う島FE＋年FE（島単位cluster）の光量係数は **−1.705413**、SE 1.114885、95% CI [−3.953794,+0.542967]、p=.13342。主たる島×本土交互作用とは別。
