## 次の認証ゲート

1. **同じ元写真ID**の画像・ライセンス・現在の観察帰属を確認。リンクエラー・非公開・削除は閲覧不能として明示。別写真への黙った差替え禁止。
2. モデルの色ラベルを見せず、2人が独立に**開花器官の有無、花被可視性、可視花色**を判定。葉／萼・苞片／背景は別カテゴリー。異議は裁定。
3. 元の写真に対応する数値strict9成功行と元ROIマスクが取得できた場合のみ、**ROIが実際に花弁を覆っているか**を確認。元試行ID台帳だけからマスク成功を推定しない。
4. 封印キー開封後に18層の精度・混同行列を計算し、層別抽出確率で全37,104種カタログへ拡張。二値flower-validと色9クラスは分けて計算。無作為な撮影分布全体・現地の自然群集への一般化は別問題。
5. 当該QA結果で、現在の水分・NPP・木質AGB・LGM回帰を（写真status、空間・分類群構成を分離して）再実行。**現段階では538写真の開花確認0、ROIマスク確認0、写真リンク全件到達確認0。**

## 生態学的な含意

MOISの現在の主要問いは水分勾配と全球の撮影花色組成。NPP/AGB/LGMは追加説明因子・歴史的種プール診断であり、花弁色の選択やレフュージアは証明されていない。高品質だけに絞ることで色の分母が偏るため、統計的な「有意」より**花冠／花被の元画像認証**と**写真分類率の色依存性の定量化**を優先する。
