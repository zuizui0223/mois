# MOIS：全球9色の地理的勾配 — WCVP地域在来植物相の独立検証（2026-11-18）

## 現在地：9色・元GBIF・GSHHG・標高・WCVP nativeを統合

2026年11月18日に、真正MOIS元37,104 COL XR accepted photo-hue species、5,493,931 accepted種×GBIF100kmセル、18,577格子の群集形成結果を、**GSHHG2.3.7の実島・大陸境界、WorldClim v2.1 10'標高、北極圏・南半球**へ割り当てた。さらに**Kew WCVP accepted unique exact binomial×TDWG3 native/introduced**判定を元5,493,931件から再生成し、広域地域内でnativeと記録された種だけで9色Shannon帰無を再評価。

WCVPの完全検証：COLXR→WCVP一意学名照合36,762種、25点/100km格子のTDWG3割当がstrict 9,288セル・moderate 10,391セル、region native strict **2,271,852種×セル**、introduced strict 436,422、native moderate 2,604,870、introduced moderate 522,378。旧WCVP原本の数と完全に一致。TDWG3の広域nativeは**個体が現地で自生する保証ではなく、島ごとの在来・固有種判定でもない**。

### 実行設計

同一37,104種の9色modal写真ROI labelを全GBIF出現セルへ固定し、**元の属×現在GBIF占有格子数5階級の中で色種ラベルだけを全球一括入替**。同じseedの199回と全種サンプルの元帰無Shannon期待を実数精度で再現。各回の全球種ラベルは同じ種が出現するすべてのセルで共有。WCVPの各セルnative/introducedは固定し、各subsetの1種1票9色Shannonを計算。

群ごとの**negative Shannon偏差 = そのWCVP植物相が、属と種の占有幅から期待されるより色ラベルが集中**。199置換からのpは同じ元種・属・地理を共有する集計の観測vs帰無であり、各100km格子を独立反復とすることではない。ただし組成の進化メカニズム・花被の真値は測っていない。

**核心：** 島や高標高では白種率に差があるものの、同属×分布域幅条件付き9色Shannonの偏差を2群で直接比較した際、差は強く支持されない。一方、北極圏と南半球では、在来種だけに限定しても9色集中の弱さが見られる。北極−北方温帯では白種率はほぼ同じ（65.99%対66.49%）なのに9色Shannon偏差が異なるため、**単純な白花率の地理勾配とは異なる9色植物相の組成問題**を示唆する。

※ここに挙げた群比較は事後探索であり、多重検定の事前固定・空間ブロック外の独立地域再現は未実施。北半球と南半球は過去の植物相の進化史・大陸面積・分類群・収集努力が違い、同緯度でも比較群が不均衡なので因果的な「南半球効果」ではない。

## 2. WCVP moderateでの同方向感度

WCVP中程度地域帰属のnativeでは8,155セル、Shannon偏差−0.02343（p=.020）。北極−北方温帯のShannon偏差差**+0.08235（p=.035）**、南半球−北半球**+0.03820（p=.005）**、南緯30–55°−北緯30–55°**+0.04452（p=.025）**。島−大陸+0.01103（p=.520）、高標高−低標高−0.00333（p=.730）。

strictとmoderateは同じGBIF/WCVP種・重複格子であり、**独立した別データによる再現ではない**。沿岸不確実性への感度にすぎない。

## 3. introduced植物相は別に解析

同じWCVP statusをintroducedへ切り替えると、strictでintroduced種30以上の3,110格子における全体Shannon偏差は−0.08525（p=.010）。高標高1,500m以上の337セルでは**−0.17430**（p=.005）、低標高500m未満の1,866セルでは−0.06262（p=.020）、高−低偏差差**−0.11168（p=.005）**。

これは「導入植物が高山で花色を進化させた」「人為移入が色を単純化した」証拠ではない。導入種群は在来種群と**種数、属構成、選別過程、園芸利用、検出率**が異なる。さらに高標高のintroduced植物群集は、地理的な種プールと観測過程が偏っている可能性がある。独立解析として、**同じ100kmセルにnative/introduced各30種以上の観測がある3,106セル**のpaired Shannon偏差を500km cluster bootstrapで評価する次段へ接続。

## 4. 研究上の見通し

- 島嶼を**真の島面積・隔離度・小島在来固有種**に広げるには、100kmでは海岸線が細すぎるため、Islandプロジェクトの真正島ポリゴンと種の島別在来分類が必須。大島を小島の代表として「島嶼シンドロームあり/なし」と断定しない。
- 高標高は実WordClim標高に基づく100km格子陸地9点中央値で、個々の写真が高山帯で撮影されたことを保証しない。対流圏の気温・降水と地理的山系を層別し、同一山系内の上下で比較する必要がある。
- 北極は冬季日射、短い生育季、植生型、気候変動史や送粉者相の違いを含む可能性があり、送粉者不足という単一機構に還元できない。
- 南半球では大陸面積、温帯島嶼の比率、古地理・科属プールの違いを含む。左右半球で同じ緯度・気候・科属をそろえた保留モデルは未実施。
- 白色種の観測比率と9色Shannon集積の違いを、ユーザーのMOIS論文では**別の結果**として表現すべき。種内花色の進化、真の花被9色、UV色素、生態的送粉者の行動は未測定。
