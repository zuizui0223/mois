# FCP マクロ生態学：環境×花色の方向は、標本選択と空間条件付けのどちらで弱まるか

**2026-10-14｜解析状態：元写真/36環境アーカイブのSHA照合・実データからの999回bootstrap・独立行列再計算PASS。** FCP PR #193における環境×4色の「方向」の追跡解析。異なる進化過程・原因を導く新しい確認的研究ではない。新規選択した世界地図、真の遺伝的色型頻度や適応度を一切作らない。

## 生態学的な問い

元FCP写真で種間の年間降水量と白写真率の勾配が正であっても、同じ属・同じ粗地理セルで比較すると弱まる。従来の分析では**観測できる種が減ること**と**異なる空間調整を行うこと**が同時に起きていた。これを次の3段階に分け、地域と色相の定義を変えずに定量する。

1. **A：同一属集合、全適格種** — 同じ粗地理セル内の適格群を持つ属に絞り、その属の他の種もすべて使う。広域地理（絶対緯度・経度sin/cos）を調整する。
2. **B：同一属集合、同じ粗地理セルに3種以上いる種のみ** — ほかの条件を変えず広域地理を調整。A→Bは属内での観測支持条件・種構成の違いを表す。
3. **C：Bと全く同じ種・元写真4色・平均環境を用いる** — 地理補正を「属内の広域座標3変数」から「属×粗地理セル内での平均差し引き」に変更する。B→Cは*同じ種集合でのモデル条件付けの違い*を表す。

A・B・Cの傾き差に対して、同一の属再標本化999回を共有し、6固定環境軸×4写真色の24対照について、各地域・重みで別々に近似maxT同時95%区間を求めた。**地理やモデルの条件を変えたときの予測的な傾きの変化であり、空間の因果効果や気候選択ではない**。世界と東経90–180°は先行研究で既に強調された事後的な範囲で、地域全体の選択を補正していない。

## 支持できること／できないこと

- **支持できるマクロの観察:** 写真で分類された種間の花色組成には全球の水分環境と広域的な共変動がある。その係数の大きさ・場合によって符号は、属の選び方・同属内の対象種・空間条件付けに影響される。
- **支持できない普遍的方向:** 「湿潤地ほど白花が増える」があらゆる植物属・独立測定・厳格画質・空間比較で同符号になるわけではない。PR #191の別測定NHM花色も東側白−青紫の方向を確定していない。
- **原因未識別:** 粗い地理セル条件付けによる減衰から「乾燥による色素合成利益」「湿潤地で白花が適応的」「空間は気候の真の原因を取り除いた」とは言えない。比較可能なBIO12の変動幅、種構成、残余空間依存・撮影光・未分類写真が残る。

## M1→M4 研究の順序と停止条件

**M1 環境×花色方向の一般化**（現在の主線）→ M2 世界花色地図（地理ごとの花色と境界復元確率 `P_hot` と帰無対照）→ M3 気候による色型の相対適応度（多系統の花色×環境×fitness 実測と操作実験）→ M4 集団内の遺伝的多型維持（遺伝子型×頻度×時間×適応度）。これらは同じ主張の証明段階ではなく**異なる推定対象**である。M1の大域的相関だけではM2で全世界に共通する境界の存在を支持できず、M2が完成してもM3選択やM4遺伝的維持機構は実験データ無しには識別できない。

元のRGFCA全球共通境界のG1検定p=0.070、別種群での境界共有p=0.856は支持なし。M1の「普遍的な湿潤→白花の方向」は未支持であり、これ以上既存同一写真で環境軸・地域・色の組合せを事後選択して有意性を捜索しない。次の必要なM1検証は、元写真内なら**近距離の位置・環境機会を保つ条件付き帰無モデル**と真の系統・同種内の比較、外部なら独立した専門家花色と植物標本座標である。
