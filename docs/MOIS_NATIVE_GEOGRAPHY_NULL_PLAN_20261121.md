# MOIS：WCVP在来限定の地理条件付き9色・白固定8色帰無モデル

作成日：2026-11-21。既存研究の継続解析として、今回の999回計算前に実装方針を固定する。外部登録された事前登録ではない。

## 主目標

前回の全球写真9色の集中が、WCVP地域在来の種×100km格子だけでも、属・全GBIF占有幅・粗い地理親和性を条件とする帰無に対して残るかを検証する。写真由来ラベルの再認証や新しい色ラベルの付与は今回の対象に含めない。

## 実行する解析

1. 元GBIF 37,104受容種、5,493,931種×格子、18,577格子と、元WCVP学名・TDWG3分布資料をSHA256で照合する。25サブ点の厳格な地域割当と、在来種×格子2,271,852行を再構築する。
2. 厳格な在来種30種以上の格子を主標本とする。100種以上とmoderate在来判定は重複する感度標本とする。従来の7,231格子・5,389格子、観測Shannon、199回の帰無期待を再現する。
3. 前回と同じ種ラベル帰無を各999回計算する。9色は属×占有幅、同じ可動種集合の対照、属×占有幅×6区分親和性。8色は白色種IDを固定し、非白種だけに対応する3モデルを用いる。seedは9色20261118、8色20261118+803。途中のp値で回数を変えない。
4. 各置換では一つの種ラベルをその種の全格子へ同時に適用する。同一置換をstrictとmoderateの両標本へ適用する。全球の最初の199回を従来の格子別期待値と照合する。
5. 全球平均、6粗区分の各平均と等区分重み、南北、北極圏と北方温帯の平均を保存する。南−北、北極圏−北方温帯は同じ全球置換内の直接差として検定し、p値の有意・非有意の差から地域差を主張しない。

## 統計量と報告

- Shannonは種数割合に基づく自然対数のエントロピー。各100km格子を等重みとし、個体数・花数・写真枚数の重みは使わない。
- 主仮説の「集中」は観測平均Shannonが帰無より低いという方向であり、順位に基づく下側pを使う。両側pは上下側pの小さい方の2倍、上限1とする。各尾は観測値を含む+1補正を用いる。
- 前回の「模擬帰無の平均からの絶対偏差」による両側pは再現確認用の旧診断値として保持し、新しい主要pにしない。
- 厳格在来の地理条件付きモデルでは、6地域平均と2直接対比を8比較の探索ファミリーとしてHolm補正する。9色と白固定8色は別仮説として別のファミリーを明記する。
- 帰無期待のMonte Carlo標準誤差、帰無統計量の95%範囲、置換ごとの全要約統計量を保存する。帰無範囲を効果の信頼区間と呼ばない。
- 同じ可動種集合の対照は、観測色の変動性に依存して可動種が選ばれるため、帰無平均の比較のための記述的対照とする。そのp値に厳密な無作為化検定の意味を与えない。

## 保持する推論境界

6区分は経度3帯と南北半球を組み合わせた座標区分であり、生物地理区・大陸・バイオームではない。種の親和性は現在の全GBIF占有格子の65%以上が同一区分に属するかで定義する。

今回の在来限定は評価する種×格子の限定である。ラベル交換の種プール、分布幅と地理親和性は比較可能性を保つため前回と同じ全GBIFに基づく。地域固有の在来種プールの中だけの交換、系統樹による制御、栽培個体の排除を完了したとは主張しない。

WCVPのTDWG3在来性は地域の種の属性であり、各GBIF記録が野生在来個体である証明ではない。写真9色は独立に認証した花被色ではない。結果は現在の記録植物相の写真色組成に関する条件付きの記述であり、送粉者選択・競争・環境フィルタリング・進化の因果同定ではない。

全植物相と在来限定では適格格子が異なるため、両者の偏差の数値差を在来性の効果と解釈しない。白固定8色と9色は母集団と帰無仮説が異なり、有意性の違いだけから「すべて白が説明する」とは結論しない。
