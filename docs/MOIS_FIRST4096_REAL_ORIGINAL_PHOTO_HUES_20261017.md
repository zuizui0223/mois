## Completed original photo pixel work

The actual first new-image processing workflow [run 38994341776](https://github.com/zuizui0223/mois/actions/runs/38994341776) processed **4,096 unique never-before-scored original photographic source IDs** from **1,000 named source species**, 4,096 distinct original observers. It restored the original ROI-v4/EfficientSAM and YOLO weights by model SHA, downloaded real original iNaturalist photographs, and computed genuinely new image masks and original four-hue class labels in 16 × 256-photo shards.

Across all sixteen source/model receipts, **1,576 photographs were classifiable as one of four hue states**; the other **2,520 photographs stayed as explicitly unclassifiable/uncertain**, not white/nonwhite, and none was substituted with a favourable image. This expands the previously signed MOIS photo universe from **248,312/120,807 classifiable** to **252,408 unique original photographs and 122,383 four-hue-classifiable images**.

These are real completed image-computation results, **not source-only candidate metadata**, and are not independently botanically verified blooming tissue nor naturally maintained plant morph frequencies.

## Source authentication and inclusion

`scripts/analysis/mois_reassemble_original_new4096_measurements.py` re-reads every original 256-photo outcome, its SHA256 photo terminal and each original model attestation, validates the original 4,096-photo source membership and all sixteen original 256-source selection SHAs, checks no exact ID overlap with previous 248,312 photos, and emits a real compressed photo-level union with a receipt. Failure/incomplete source-photo shards are **fatal** and may not silently reduce analysis denominators.

The prior 248,312 photographs were frozen in [original MOIS source run 38990701473](https://github.com/zuizui0223/mois/actions/runs/38990701473), while first source 4,096 were selected from exact 3,430,502 original iNaturalist IDs in [MOIS run 38994341776](https://github.com/zuizui0223/mois/actions/runs/38994341776). Four-hue source outcomes are not fitted as an FCP D/W photo-geometry statistic.

A disjoint **second 4,096** original-photo wave is concurrently being measured from *outside* the first 106,376-photo screen, sourced from the authenticated 3.43 million-photo original source. Its pixels/results are NOT included in the first-wave figure until **all sixteen** receipts finish. These additional photos can be added without re-running the existing original 252,408 photographs.
