# 環境全体の花色予測情報は白―有色軸に集中するか？（2026-10-11）

## 生態学的な問い

36環境変数（あるいは土壌欠測を避けた26変数）を一緒に用いると、同属の未知種の4色写真比率が地理＋属の基準より予測しやすくなることは確認した。しかし**改善のどの部分が白に、どの部分が赤桃・黄橙・青紫に対応するか**は、全色を一括した多クラスBrierだけでは見えない。これは、前向き確認された白―有色表現型方向と環境全体の観測的な関連を接続するための検定である。

元原写真42,111名義種、重複除去100,543写真ID、4色元判定45,953枚。地理＋属基準モデル vs 地理＋属＋全環境モデルは、主PR #166の**同じ種等重み・属等重み、同じ5 geographic centroid-cell folds、同じ訓練種・未知種、同じ4色の正規化**で比較する。各色cの寄与は予測値pを使い `(p_geo,c-y_c)^2-(p_all,c-y_c)^2` で計算。4色合計が必ず多クラスBrier改善に一致する。属クラスタ499 bootstrap、背景・画像分類・適応度を別の測定と混同しない。

## トレードオフ説への推論の境界

白と3つの有色の確率は合計1で互いに制約を受けるので、白の誤差改善が4色合計の約半分という割合は、白色素損失コストや適応度の分散の約半分を意味しない。モデルは観察写真の4色、元花領域の分類確率ではなく整数ラベルの集計に依存し、白ラベルと撮影露出の結び付きが既知。色素化学、花粉・種子数、送粉者、食害者、局所UV、遺伝的白/色対立は未測定。生物学的な仮説は、**共通の白―有色表現型空間が環境複合勾配に沿って変わり得る一方、その結果を生む利得と維持コストは環境・植物相依存かもしれない**、にとどめる。

この解析は事後的な観測的予測検定。土壌あり／なし、東西、画質により評価種が異なり、5fold地理holdoutは写真地点の完全GPや年代付き実系統樹ではない。原New Phytologist H1/H2、main、未使用コホートは不変。
