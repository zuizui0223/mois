# MOIS: GBIF × WCVPで検証した科固定の自生・外来植物相属分離（2026-11-16）

## 現在地・推論上の結論

**GBIFとKew WCVPによる分類学的な結果。花色写真を今回の応答変数に使用していない。** 各100km格子の自生・外来植物相は、種数と属ごとの種数を固定したラベル無作為化期待より共通属が少ない。さらに、**WCVP科ごとの自生・外来種数も固定しても**共有属不足が残る。

ただし、LGMからの気温変化と帰無補正済み属重複との小さな関係は、科固定後に統計的に明確でなくなった。この結果は当時の実在レフュージア、歴史的分散や外来の定着過程を復元していない。

## 定義と帰無

各格子における各属 `g` の確認種数を `m_g`、native/introducedの種数を `N_n,N_i` とし、`N=N_n+N_i`。

`P(gが両群にある) = 1 - C(N_n,m_g)/C(N,m_g) - C(N_i,m_g)/C(N,m_g)`。

- 従前の「全種数条件付き帰無」：格子全体の `N_n,N_i,m_g` のみ固定し、statusを一括再配分。
- **今回の科固定帰無**：同一格子の**各WCVP科 f の** `N_{n,f},N_{i,f},m_g` を保持し、その科内でのみstatusを無作為配分。
- 帰無期待共有属数を足し上げ、固定の属和集合数で除算し、期待Jaccardを得る。観測値と期待値の差は、群集・系統内での現在のnative/introduced区別と関連するが、過去の生物学的な置換イベントの数ではない。
- 明らかに同じ文字列の属名が複数科に現れる可能性を排除するため、今回の属カウントの単位は**科×属の一意組合せ**とし、科情報不明を勝手に補間しない。実際に自生・外来として扱った元種×格子で欠損は0。
