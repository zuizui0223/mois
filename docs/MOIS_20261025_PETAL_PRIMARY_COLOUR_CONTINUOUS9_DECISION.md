# MOIS 花弁主体の全球花色：9成分・主要色・クラスタリングの推定対象整理（2026-10-25）

> **更新（2026-10-25）：本書の「花弁・萼・花芯を個別に識別することを前提にする」記述は研究方針から外した。** 現行の決定は [優占花領域色＋CIELABの明度・彩度・色相＋白/緑/褐の島嶼解析](MOIS_20261025_ISLAND_FLORAL_DOMINANT_LAB_WHITE_GREEN_BROWN_PROTOCOL.md) を参照。既存flower ROIで優占色を実用的な「推定主要花弁色」とし、器官別セマンティックセグメンテーションを必須工程にしない。本ファイル以下は検討履歴として残す。

## 結論

主応答は**検証済み花弁・花被（必要に応じて頭花の各小花）画素の連続色分布**。9成分は元画像の出典追跡可能な**準主解析**、花弁の主要色は連続分布から導く**補助要約**、個々の写真のクラスタリングは**探索**とする。写真1枚全体、YOLO検出箱、EfficientSAMの*flower union*、実際のpetal maskを同一視しない。

## 既存104万枚を使った実測判定

実データは1,043,930原写真、459,235自動4色ラベル、390,541厳格9成分ROI、36,224曖昧9成分（探索のみ）、584,695自動4色unknown。[原本由来9成分の保存版](https://github.com/zuizui0223/mois/releases/tag/mois-original1043930-recovered-continuous9-426765-and-ecology-20261025-v1)。

厳格390,541件で**最も多い1色パレット成分の占有率**を、元の9要素から計算した：[GitHub Actions実走行 #40196064110](https://github.com/zuizui0223/mois/actions/runs/40196064110)。

| 主要な9成分占有率の特徴 | 実測 |
|---|---:|
| 最大成分の中央値 | **80.25%** |
| 最大成分 >=50% | **91.19%** |
| 最大成分 >=70% | **64.85%** |
| 最大成分 >=90% | **33.07%** |
| 10%以上の成分が2種類以上 | **59.42%** |
| 同一の9成分から再構成した4色と元の自動4色の一致 | **99.13%** |
| 元4色は有色でも9成分の最大が白 | **2,560枚** |

最後から二番目の一致率は**入力の数値定義が同根の内部整合性**であり、花弁を人手で検証した正解率ではない。最も多い色成分が白でもピンクの花弁／花芯・萼・露出差を拾う可能性がある。

### モデル仕様の落とし穴

凍結した[FCP flower_roi_v4_runtime.py](https://github.com/zuizui0223/fcp/blob/9fae6ccdf684a46026f72ba12e98de2c5c54bf2a/fcp_pipeline/flower_roi_v4_runtime.py)は、YOLO検出箱をEfficientSAMへ渡して得た**複数flowerインスタンスのunion mask**に対してLab分布を集計する。これは**花弁／花芯／花被／総苞の器官セマンティクスを識別したmaskではない**。集計後の9数値から花弁ピクセルの分布を厳密復元することはできない。

## 推奨する各出力の最小単位

**写真 photo_id → 花インスタンス flower_id → 器官 organ_class** を維持し、色が取れない実写真も台帳から消さない。入力段階で複数の花・頭花・花序を写真の単一色に混ぜない。

1. `petal_mask`: 花弁/花冠/花被片（植物群によってpetaloid sepalとray floretを別タグで許容）、葉・萼・花芯・総苞を分離、器官不明は`unresolved_organ`。真の花弁がない場合に無理に花弁色を作らない。
2. `petal_lab_distribution`: 花弁マスク内の色校正条件・撮影品質と併記したL*, a*, b*中央値、分位点、彩度C*分布、色相のモード/分布。**無彩色付近の色相は不定**なので欠測・区別を保持。
3. `petal_palette9`: 9つの非負比率（合計1）として保管。9次元単体の構造を壊さずHellinger/JS距離またはゼロ対処付きlogratioモデルで利用する。9成分のラベルを生物学的に異なる9種類の色素と呼ばない。
4. `main_petal_colour`: **花弁だけの画素**で、最も広い面積を占める知覚色モードの代表Lab色（決してROIの9カテゴリmaxを主色の真値にしない）。`main_mode_fraction`（占有率）、第二モードの割合、モード不確実性を必ず付す。例えば主要モード >=70% は**仮の表示条件**であり、閾値を動植物標本のホールドアウトで較正するまで確定しない。花弁に2色大きなモードがある場合は`multicolour`とし、強制的に「白」「有色」にしない。
5. `image_quality`：花被マスク誤り、背景漏れ、茶色枯死部、過露出/陰影、複数被写体、部分的に隠れた花弁、非開花、撮影距離、過度な色編集等の独立した観測過程フラグ。植物が生物学的に白かどうかとは別のQC。
6. `source_provenance`: 写真ID・観察ID・植物同定・日時・地点・原出典・ROI9採否・独立レビュー確率・学習/推論モデルSHA、元の4クラスラベル（比較用のみ）。

### まず既存データでできることとできないこと

- **できる（完了）**：旧9成分390,541枚で、白成分率、9成分エントロピー、主要9パレットの占有率、属/気候/島/季節の関係を解析できる。旧4色は既存論文比較として利用。曖昧36,224は感度解析専用。
- **できない（未実行）**：花弁器官の真の主要色、各花弁の色モード・二色性を**9成分だけから復元すること**。ソースROIマスクは器官セグメンテーションではないため、元画素または残存マスクを再参照し、人手で花弁/非花弁の参照ラベルを作る必要がある。

## 93,209,351全件に適用する計算戦略

**全写真を一度だけ軽量画素走査、必要な花被器官だけ高品質に追測**。YOLOの「花候補あり」を単にStage2送りの条件にすると初期実測で約97%が候補となり非効率。そこで単一の軽量花弁/花被画素セグメンテーション（例：蒸留した小型セマンティックセグメンタを500px候補領域にバッチ適用）を別途訓練/検証してから、全画像の暫定petal colour特徴を画像と同じ1パスで保存する。

検証セットは独立の人手花弁ピクセル領域・萼/花芯/葉・二色花・小花・開花状態、白花/有色に偏らず属/地域/季節/撮影条件で層別し、**学習とは異なる属/地域/観察**にも一般化できるかを評価。花弁IoUだけでなく主要Lab色誤差、白色成分の偏り、混色率、色相誤差（低彩度除く）、ROI陰性の見逃しを主要指標にする。既存の390,541自動ROI9は弱教師・補助参照になるが、人手の花弁真値としては使わない。

9成分クラスターの数Kを仮定して源写真を「4花色型」に置く必要はない。必要なら器官検証済み色組成に対して、Hellinger/JS距離・クラスタ安定性・連続モデルとの適合比較を行い、**生物学的な分離の根拠が出たときだけ**副次表現とする。

## 解析上の最終回答

**「花色空間は連続的」**を主仮説の出発点に置き、1花（器官）ごとの色の中心・彩度・色相・複数モードの割合という形質を記録し、湿度/標高/島嶼性/季節に沿う分布をマクロ解析する。**主要色は派生特徴。クラスタリングは自然な色型が存在するかを後から検証する手段**。メタデータだけの93mは画像色測定済み扱いしない。
