# MOIS・種別9色ROI成功数の履歴非破壊修復（2026-11-14）

## 結論

初期の分類群別台帳（2026-11-10、42,111分類群）では、独立数値ROI観察数が同種の数値ROI成功写真数を超える不整合は **0**。2026-11-14の更新台帳では **3,812分類群**にこの不整合があり、うち **653分類群**で累計写真成功枚数が初期値より減っていた。

原因は、第8波～第57波の更新コードに存在する、成功画像追加の際の 'prev.loc[gids, "after_strict9"] = 1' という代入。既に数値ROIを持つが代表色不明瞭で再取得対象だった分類群でも、累計成功枚数を「1」に**上書き**していた。一方、同じ更新処理の 'independent_roi9_observations = old_counts + 1' は観察単位で増分を保持していた。画像から計測した9色数値・代表色の消失ではなく、**分類群別累積成功枚数の二次台帳の問題**。

## 修復の根拠

3つの元データは、それぞれ元GitHub Actions artifact ZIP SHA256と内部CSV SHA256で固定し、勝手に更新しない。

1. 初期atlas: [Actions 42843867854 / artifact 13776829802](https://github.com/zuizui0223/mois/actions/runs/42843867854/artifacts/13776829802)。全原画像 1,181,146試行・451,643数値ROI。
2. 11月14日更新atlas: [Actions 43566369683 / artifact 14102611429](https://github.com/zuizui0223/mois/actions/runs/43566369683/artifacts/14102611429)。1,231,337試行・467,565数値ROI。
3. 同じ更新atlasを参照する37,103受容種のCOL XR: [Actions 43566923701 / artifact 14102518161](https://github.com/zuizui0223/mois/actions/runs/43566923701/artifacts/14102518161)。

独立写真・観察UUIDの排他が署名付き各波の条件であるため、修復式は次のとおり：

- 訂正後の種別数値ROI数 ＝ 初期種別数値ROI数 ＋（最終種別の独立数値ROI観察数 − 初期種別の独立数値ROI観察数）
- 元写真処理増分: **50,191** = 種別写真試行増分の総和
- 元写真数値ROI増分: **15,922** = 種別独立数値ROI観察増分の総和
- 種別補正数の総和: 初期 441,493 + 増分 15,922 = **457,415**

独立観察の増分が数値ROI成功の原写真増分と一致しない場合はエラーとして停止する。未測定色の補完・過去の写真の再推定・旧署名付きデータの書換はしない。

修復コード： [scripts/analysis/mois_reconcile_strict9_counts.py](../scripts/analysis/mois_reconcile_strict9_counts.py)。回帰テスト：[tests/test_mois_reconcile_strict9_counts.py](../tests/test_mois_reconcile_strict9_counts.py)。CI：[mois-reconcile-strict9-counts.yml](../.github/workflows/mois-reconcile-strict9-counts.yml)。CIは42,111分類群の訂正台帳・37,103 COL XR受容種の訂正対応表・修正した3,812分類群の差分を別artifactで出力する。

## 生態学的評価への影響

分類群の代表色頻度（白色は39,172分類群のうち22,121、56.47%）は変化しない。ただし、信頼度や撮影頻度による重み付き比率は変わる。**代表色のある分類群だけで数値ROI成功枚数を重み付けした白色割合**は旧57.7172%から訂正57.4252%（約 -0.292パーセントポイント）となる。この数値は測定画像における算術的割合であり、全球の野生植物の白花率ではない。

強調：サンプル内の一致は種全域で固定した花色の直接証明ではない。混合色やbronzeは非花弁領域の影響の可能性がある。全球GBIF occurrence SQL 149件は準備のみで、認証付きの全量分布取得は未実施。植物学的花器官検証と観測バイアスの評価はこの計数バグの修復とは独立に必要。

## 今後のコード規則

歴史的な第8～57波の計算記録と凍結済み原本は追跡用に維持する。**今後の新規写真ROI計測では after_strict9 を1で上書きしないこと**。必ず前回の累計数に新規成功の数を加算し、全分類群について「前回比で累計成功数非減少」「独立成功観察数以下にならない」「種別成功数の増分合計と署名付き写真成功増分が等しい」の3つを強制する。
