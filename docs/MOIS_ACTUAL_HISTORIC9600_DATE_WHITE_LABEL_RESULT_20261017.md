## 2. Summer–winter photographic white proportion in a separate globally broad historic source

Using only the recovered original historical 9,600-hash cohort, hemisphere-specific local meteorological seasons (tropics excluded) and **original photographic ROI colour classification**:

| Source photos | Local winter white / classifiable | Spring | Summer | Autumn |
|---|---:|---:|---:|---:|
| North extratropics | 38 / 87 = **43.68%** | 293 / 631 = 46.43% | 496 / 1,015 = **48.87%** | 73 / 152 = 48.03% |
| South extratropics | 60 / 171 = **35.09%** | 180 / 410 = 43.90% | 139 / 289 = **48.10%** | 76 / 157 = 48.41% |

The historical randomly photo-selected source's summer–winter photo-white excess is approximately **+5.19 percentage points in the North and +13.01 in the South**. The separately sampled high-depth/completed-ROI source before this expansion showed +3.30 North and +17.23 South, so the directional summer excess is visible in *different sampling frames*, not necessarily independent biological providers.

The historical 9,600-date photo subset spreads across a much broader set of nominal taxa, frequently with one photo per taxon. Recovered dates enlarge the descriptive **seasonal composition of photographed taxa**, but do not establish repeated observation of *open flowers within the same species, biological locality and original season-year*. The classifier itself labels visible ROI hue, with nonrandom unclassifiable photos and some possible bracts/fruits.

## 3. Why this is useful and what is not yet proven

This actual 9,600-photo source measurement has established: historical `observed_on` missingness was a metadata-export problem that can be substantially repaired by exact original photo/observation ID verification; the extra source adds 4,305 genuine dated hue outcomes; and a photographed-summer-white descriptive excess persists in a broader/shallowly sampled source frame. It does **not** demonstrate seasonal pigment plasticity, floral reproductive fitness or independent seasonal water/light adaptation.

**Full 100,543-date recovery is a separate source-validation task.** Provider recommends bulk export or official monthly open dataset for more than 10,000 records, not indefinitely repeated small public API batches. The independent [iNaturalist S3 monthly open-data source investigation](MOIS_OFFICIAL_MONTHLY_OPEN_DATA_FULL_HISTORICAL_PHOTO_DATE_SOURCE_20261017.md) describes exact original photo ID → observation UUID → `observed_on` with verified provider source ETags; current monthly snapshots may omit restricted-license or deleted source photos. Any full-source result must be reported with actual coverage, not scaled up from 9,597/9,600.

The original frozen 267,425-photo global among-taxon moisture model and FCP's separate intraspecific W/D/local photo-polymorphism model are **unchanged**. No actual observed-year TerraClimate weather, anthocyanin pigment, pollinator choice or fitness mechanism is inferred from this source date enrichment.
