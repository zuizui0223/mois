# MOIS 2026-11-18：同一100km格子の在来・導入植物相の9色集中差、標高・島・南北感度

## 重要な新しい生態学的発見候補

GSHHG2.3.7島・大陸、WorldClim2.1実標高と、WCVPのTDWG3 regional native/introduced状態を真正MOIS 37,104 accepted photo-hue species / GBIF 5,493,931種×100km格子へ結合。**同一100km格子で在来種・導入種がそれぞれ30種以上記録される厳格WCVP 3,106セル**に限定し、同じ場所・同じ環境に存在する種プールのShannon9色（観測−同属×分布域幅199回null）をペア比較した。

**高標高（同じ地理セルのWorldClim10分標高9点陸地中央値≥1500m）では、WCVPで導入と分類された植物種群は、在来種群より白写真ラベル種割合が約9.5pp高く、9色Shannonが属×分布域幅からの帰無期待を下回る程度も大きい。**低標高ではこの在来−導入差は非常に小さい。500km空間ブロック20,000回bootstrap、両statusの少ない群の種数でセルを重み付けても、高低差の方向と区間が維持された。

これは**「高標高では白花の植物が導入されやすい」「導入で色が単純化した」ことの因果証明ではない**。元ラベルは写真ROI9色proxyであり、WCVPの導入はTDWG3広域種分布の記録、現地に導入されて定着した個体や導入時点の花色、栽培からの逸出、送粉適応を直接測らない。高標高の導入種群は自然史・園芸選別・分類学・地域種プール・観察過程が偏りうる。

## 1. 同一格子の比較方法

各セルcについて
- 在来群写真白率 `Wn(c)` と導入群写真白率 `Wi(c)`、`ΔW = Wn − Wi`。
- 在来群の9色Shannonの属×GBIF占有幅199global-permutation残差 `An(c) = Hobs_n − Enull_n`、導入群 `Ai(c)`、`ΔA = An − Ai`。ΔA>0は導入群の方が帰無期待に比べて色の集中が強い方向。
- 各地域で500km equal-area blockを20,000回復元抽出し、セル等重みと`min(n_native,n_introduced)`重みで区間を計算。高低差などは**同じbootstrap反復で同じブロックを同時再抽出**することで依存構造を保持する。
- **厳格3,106セル / moderate3,602セル**。これらは同じ元データと大量に共通格子を持つため独立再現ではない。北極圏では各status30種を持つ厳格セルが12しかなく、北極のnative−introペア比較は**データ不足として検定せず**。北極の在来のみ検証は別のsigned native analysis参照。

## 3. 島と南北半球のペア比較

厳格の**島159セル**と大陸2937セルで、native−introのShannon偏差差が島の方でさらに強いかを比較したが、差の差−0.02304［95%CI −0.06210,+0.02110］と不明確。少数群重みでも−0.04811［−0.08657,+0.01409］。島は多数が巨大島の100km陸上格子で、小面積島・隔離度・島内在来固有種の推定ではない。

南半球と北半球でのnative−intro Shannon差の差は厳格等格子重み+0.00810［−0.01392,+0.03012］で不明確、少数群種数重み+0.03275［+0.00792,+0.05691］で正。ただし格子群・花色群の構成は地理的に異なるため、南北歴史・送粉者差の因果ではない。南緯30–55° vs 北緯30–55°では厳格+0.03988［+0.00578,+0.07467］（重み+0.04880［+0.00981,+0.08857］）だが探索的、重複する地域に対する多数の検定であり単純な南半球機構とはしない。

## 4. 他のMOIS結果との接続

**同一格子の色多様度の違いは、global WCVP native/introの花色組成差と矛盾しない。** 以前の同一セル白率差は格子等重み−2.98pp、少数群種数重み−1.47ppだった。ここではさらに色数・Shannon多様度の属×分布幅null偏差を使い、高標高に強い異質性がある可能性を示した。WCVP-nativeのみのグローバル9色群集形成はstrict native7,231セルでShannon偏差−0.02498（p=.020）。北極・南半球では弱い集中という別の地域パターンも実証。ただし高標高・北極・南半球の違いを一つの単純な「送粉者希少」機構に押し込まない。

次に生態学的に必要なのは**同じ山岳帯内・同じ緯度帯でWCVP native/intro種プールと気候をそろえた比較**、導入経路/園芸種性の調整、そして真の花被色の独立認証。今回のp/区間は現代の記録植物群集の構造であり、適応・生存率・花粉制限を測っていない。
