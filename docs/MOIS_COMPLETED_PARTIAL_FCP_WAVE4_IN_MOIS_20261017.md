## What the new import actually does

`scripts/analysis/mois_reuse_fcp_wave4_completed_roi_partitions.py` reads the exact original [FCP 49,800-photo blinded source firewall](https://github.com/zuizui0223/fcp/actions/runs/38992543115) with signed SHA256 `3e270153134830496357f537f0dee0544647d492dcf751e856988d36ce1e502a` for the `measurement_id` → original photo/species/observer/date/site metadata table. Every finished original photo-pixel partition is validated against the original **outcome-blind** 49,800-image partition assignment lottery, SHA-frozen source receipt, original workflow version, full actual photo terminal (including failures), photo-level ROI colour state, image checksum for classifiable photos and scientific absence of location/taxon in the model input packet.

It joins these **actually finished** original ROI colour outcomes to the 252,408-photo MOIS file by original `photo_id`. A repeated photo ID is counted only once, the old MOIS classifier decision is retained and any independent terminal classifier disagreement is recorded, not silently overwritten. It outputs an actual compressed photo-level dataset, partition-completion ledger, source checksums and a new legitimate four-hue classifier denominator. **All FCP partitions not yet completed remain unmeasured and are not counted**, and the interim sample is labelled as **potentially biased by GitHub job completion order**, not a globally representative independent source replication.

The imported FCP value is the *photo-level original four-colour classification*, not its `W`, `D`, within-species spatial clumping or inference about genetic colour polymorphism.

## Immediately apply original water method to real new data

The separate module `scripts/analysis/mois_refit_water_FCP_wave4_partial_real_ROI.py` uses the **same original prespecified six abiotic anchors × four photographed hues**, nominal-genus conditioning and genus-equal weighting, 999 genus-bootstrap draws and maxT familywise 95% intervals. The earlier 248,312-photo per-image WordClim BIO/solar source remains SHA-verified. **Only genuinely added photographs** receive new official WorldClim v2.1 BIO5/BIO12/BIO14/BIO15, long-term solar and 12-month vapour climatology site extraction. Missing or unclassifiable photograph hue stays out of four-hue means.

This is a **provisional** expansion while FCP wave4 is incomplete, not a formal final confirmation based on all 49,800 new image results. The full future 49,800 import is separately gated under merged PR #29 and will deduplicate/replace source-snapshot membership when all 256 original partitions finish. The historic 100,543-photo, 248,312-photo and 252,408-photo moisture results remain frozen.

`.github/workflows/mois-real-fcp-wave4-completed-partitions-water.yml` actually downloads whatever original partitions are **completed** at the start of the run, computes their source-authenticated photo-ID union and refits the original water model, publishing actual original images' measured outcomes and exact data receipts. It does not invoke a new classifier on old photos and does not count any incomplete FCP partitions as measured.

**Limitations:** The source/photo classifier is not independent botanical confirmation of a currently open flower or an allele frequency, and global water-vapour/rainfall gradients are observational, not a pigment-cost or pollinator-dependent fitness experiment. The within-genus coarse same-geography-cell maxT sensitivity must accompany every positive global water claim.
