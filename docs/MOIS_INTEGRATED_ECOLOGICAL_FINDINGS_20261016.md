# Mois/FCP 研究成果の統合：全球花色の生物地理・分類群構成・水分環境

**2026年10月16日／論文編集用の科学的総括。** 対象は「花の可視色」だけ。果実色・種子散布色・別プロジェクトの新規形質解析は含めない。主資料は FCP から継承した同じ写真・環境ソースの復元結果と、別研究グループが手作業で分類した花色データ。**新たな降水量実験や遺伝子型・繁殖適応度の測定は行っていない。**

## 一本の問いと回答

**問い：世界規模で観察される花色―水分環境の関係は、各種に共通する環境応答なのか、それとも分類群の歴史・種構成と比較尺度に条件づけられたパターンなのか？**

**回答：広域で白色の花写真の比率は湿潤な環境ほど高いが、その傾向は属平均の差で強く、同属種間にも弱い正の傾向として残る。一方、属ごとの寄与方向は混在し、種内・局所・厳格な写真条件・新しい属の種間差へそのまま一般化できない。** この「広域の相関と生態学的な局所可搬性のずれ」が論文の中心。分類群構成だけがすべてを作った、または雨が花色進化を直接起こしたという因果主張ではない。

## 信頼できる主要結果：同一出典・異なる推定対象を明示

| 質問・推定対象 | データと効果 | 生態学的解釈 |
| --- | --- | --- |
| 世界の花色比率は本当に半々か | 元の**100,543枚**のうち**45,953枚**が4色分類可能、白**21,574枚（46.95%）**。分類可能な種を等重み：**46.82%**、全**5,369属**平均の等重み：**49.89%**、5種以上を含む**1,185属**では**46.63%** | 約50%はサンプル・重みづけに依存。遺伝的な白／有色形質の平衡頻度ではない |
| 花色は属ごとに偏るか | **20,725種／1,935属**：属平均への分散帰属**34.38%**、属サイズ維持のランダム色割当てでは平均**9.33%**。降水・緯度・写真深さの粗い層別置換でも帰属差は残る | 花色には強い分類群構成があるが、属が単系統であることや系統的保存性の直接検定ではない |
| 湿潤な場所に白花が多いか | 元データの**20,694種／1,934属**。属内・広域地理調整後、年間降水量 BIO12 に対して白写真比率**+2.255ポイント／ソースSD**（元の24対比同時95%区間 **+0.319～+4.190**）、年平均水蒸気圧**+3.952**（**+1.199～+6.704**） | 分類群内にも広域で正の方向がある。強い局所適応・因果選択・全属に共通する法則とは違う |
| 属平均と同属種間の勾配はどちらが大きいか | **全く同じ20,694種／1,934属**、同じソースSDと広域地理調整。降水量：**属平均+8.555、属内+2.255**、同じ属の再標本化で差**+6.300ポイント**（通常95% **+3.666～+8.779**）。水蒸気圧：属平均**+9.370**、属内**+3.952** | フロラの構成／歴史と同属種間の環境勾配が別の比較層で働く。2係数の比は因果的な分散分解ではない |
| 正の関係は属ごとに同じか | 年間降水量の世界的な属内モデルへの符号付き寄与は**830属で正、719属で負、385属で白写真変動なし**。白写真変動のある1,549属のうち正は**53.6%**。正の寄与量の約**60.3%**は上位10%の属に集中 | 世界全体の方向が正でも、各属の方向・寄与は不均一。個別属の有意な傾きの件数ではない |
| 同属種間の差をどれだけ予測できるか | **別集団16,801種／1,665属（soil36完全ケース）**。13環境変数による属内白写真割合の記述的説明率は**0.6202%**。未知属の2種間の白写真差の予測で、広域地理だけから降水量・水蒸気圧を加えると平均二乗誤差**0.316285→0.315620**（約**0.21%**改善、95%差区間**−0.000227～+0.001506**でゼロを含む）。4種類の属分割すべてで増分の区間はゼロを含む | 環境には広域の統計的関連があるが、未知の同属種の違いを精度よく再現する単純な一般則にはまだならない |

**異なる母集団を混ぜない。** 属の色集中（20,725種）、属間/属内水分勾配（20,694種）、土壌完全ケースと予測（16,801種）はそれぞれ違う対象。34.38% と 0.6202% は同一標本の分散寄与の内訳ではない。「34.38% が系統、残りが環境」などとは書かない。

## 独立した *花色のみ* の分類による外部補強

[Sinnott-Armstrong らの Dryad 花色列](https://doi.org/10.5061/dryad.r4xgxd2sc)では、**2,960種／51系統群**の手作業で記録された可視花色を使用。白**1,449種（48.95%）**だが、白／非白の変動の**27.48%**が51系統群の構成に対応（系統群サイズを保持した置換帰無平均**1.68%**；9,999回、片側**P=0.0001**）。**12/51群**で白が10%以下または90%以上だった。命名属から再集計した **2,902種／68属**でも分散帰属**28.57%**（帰無平均**2.31%**）だった。

これは**別の花色ラベルでも分類群による偏りがみられる**ことを支持する。ただし元のMo​​isの自動写真分類と観察媒体が一部重複する可能性はあり、原著の選択した51群は全球の全植物から無作為抽出されていない。**独立した花色―降水量の符号の再現ではない。** 原CSVの他の形質列は研究対象としない。

## 主要な不一致は隠さず、結論の「尺度」を定義する

1. **写真品質・局所比較：** 厳密な花ROIのソースで降水量係数 **+1.229 [−2.046,+4.504]**、同属×粗い地理セル比較で **+0.808 [−3.556,+5.172]**（いずれもソース内の同時95%区間がゼロを含む）。正の点符号は残るが局所普遍性を保証しない。
2. **同じ元写真を使った種間／種内比較：** **21,448枚／6,143種／787属**の雨量方向は同属種間 **+2.722 [ +0.705,+4.714 ]**、種内 **−0.511 [−1.436,+0.335]**、差 **+3.233 [ +1.175,+5.400 ]**（探索的・通常の属bootstrap区間）。「種内に効果がない」と断定するのではなく、この観測設計では同じ正の方向が確認されなかったと書く。
3. **分類不能とMNAR：** 100,543枚のうち**54.3%**が4色不明。乾燥側と湿潤側の元画像の分類成功率は**49.4%対39.1%**、分類成功時の白割合は**41.80%対53.25%**。不明色の条件次第で潜在的な雨―白の差は消え得る。調査されなかった色を勝手に補完しない。

これらは全世界の種群に対する「広域の正の源泉条件付き関係」と矛盾しない。一方、これらがある以上「雨が直接白花化を進化させる」「全属が湿潤地で白くなる」「白／有色が50:50に進化的に維持される」とは結論できない。

## 伝えるべき生態学的解釈（推論レベル別）

**経験的に支持：** (i) 全球の写真分類可能な花色の分布は環境勾配と共変する。(ii) 分類群平均の差が同属種間の差より大きく、各属の関係方向は均一でない。(iii) 独立に手作業分類された花色でも分類群への集中がある。(iv) 広域パターンの局所・種内・未知属への可搬性は限定的である。

**整合的だが未識別の仮説：** フロラ組成の生物地理的変化、属間の保守的な花色形成経路、送粉者環境、乾燥・光環境における色素の利益／コスト、観察者による写真選択。属は分子系統共分散ではなく、色素合成量・訪花・花粉・種子・生存などの選択は測っていない。

**検証していない：** 独立したGBIF出現座標と気候ラスタを結んだ原著外の白花―BIO12再現、斜面形状などの真のDEM地形、色素合成コストと繁殖成功のトレードオフ、遺伝的な50:50平衡。これらの作業は投稿本文の主張に先取りして混入させない。

## GEB論文の構成と結論の優先順位

1. **Introduction:** 地球規模の花色―環境関連は既知。新規性は「分類群差・生物地理・観察データによる尺度依存性」である。
2. **Results第1部：** 4色分類と写真欠測、ほぼ半々の全球花色と分類群による集中。
3. **Results第2部（主結果）：** 白―水分の正の勾配と、**同じ20,694種での属平均＞属内勾配**。属の寄与方向の混在もセットで示す。
4. **Results第3部：** 局所/厳密写真/種内の限界、地理・標高・土壌の共線性、未知属の同属種間差を予測しにくいこと。
5. **Discussion:** 分類群構成と種間生態の違いが共存する。真正の原因と選択実験は別のレベルの問い。旧FCPの深度の高い種内研究は別論文である。
