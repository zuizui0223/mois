# MOIS｜全球9色群集集中の生物地理・白／有色ゲート（2026-11-21）

## 結論・現在地

**全球の記録植物相で、写真由来9色の地域内集中は、属・種の分布域幅に加え、種の広域的な地理分布傾向を固定してもほぼ同じ強さで残る。一方、白ラベルの種・分布を固定して有色8色のラベルだけを交換すると、追加的な色集中は確認できない。**

この組み合わせから言えるのは、**白ラベル／有色ラベルのどの種がどこに分布するかという組成構造が、9色全体の結果に重要**ということ。真の花被色・有色8色の独立した収斂・送粉者選択・環境適応・歴史的氷期残存を証明したわけではない。**11/21の新規地域条件付き検証は全受容種を対象とし、WCVP strict nativeのみへの再計算は未完了。**

## データと新しい帰無モデル

元GBIFの37,104受容種、36,758種の利用可能格子、**5,493,931種×100 km格子・18,577格子**と、種ごとの既存写真ROI9色ラベルをそのまま保持。GBIF元3.96億記録からのソースZIP SHA256 `422f6d6489e61c6e57c5d51db614e47f613039781a901e3fd3481c13b2b085c2`、受容種/写真9色原本ZIP SHA256 `d8b97528188d9f8d63cb802d5b3f6e8f7f251937fd30af42aeae47e43ebad1fc`、内側Parquet SHAは原receiptと照合済み。

地理区分は、各100 km格子のEPSG:6933中心位置から定める**南北半球×経度3分割（経度＜−30°, −30～60°, ≥60°）の計6区分**。種が占有する格子の65%以上がその1区分にあるなら、その地域を**種の地域的親和性**として与え、そうでなければ広域分布群とする。**生物地理区・植生帯・独立した祖先分布史ではなく、現在のGBIF分布で定義した操作的区分**。元の属別色構成・各種の実GBIF占有格子、属×占有幅5階級と1種1写真ラベルの同時適用は固定。

元EPSG:6933格子に含まれる27極域境界セルは逆投影で中心緯度を定義できないため、その緯度を欠損のまま保持。南北区分だけ元の投影Yの符号から決定。地理的な欠測を実緯度で埋めない。この27セルは元strict WCVP在来資料では在来種数0の格子だったが、全GBIF格子そのものは除去しない。

**同じ種のラベルを全球のすべての出現格子で共有し、199回の帰無置換を行う。** 局所格子を独立サンプルや独立反復とみなさない。地域条件付けにより動ける種が減る影響を分けるため、**6区分帰無と入れ替え可能な20,760種を完全一致させ、地域条件だけを取り去った追加対照**も実装。

## 3．白を固定した有色8色Shannonで新たに何が分かったか

**白色ラベル種の同定と全地理出現パターンを固定**し、既存の非白ラベルの種の間だけで黄・橙・赤・ピンク・マゼンタ・紫・青・ブロンズを交換。対象は**有色30種以上の10,388格子**（100種以上は6,187格子）。色の部分集合を白と交換しないため、9色全体の帰無とは異なる仮説・推定対象。

| 非白8色の帰無 | 入替可能な非白種数 | 観測−帰無の非白8色Shannon差 | 両側p |
|---|---:|---:|---:|
| 元の属＋分布域帰無を再現 | 9,664 | −0.005570 | .530 |
| 6地域帰無と同じ7,667種に制限した対照 | 7,667 | −0.003771 | .600 |
| **属＋分布域＋6地域、白を固定** | **7,667** | **−0.006630** | **.325** |

6地域条件付きでも、非白8色の追加的な集中は支持されない。非白100種以上の格子でも新しい6地域帰無差は−0.010297、p=.110。**「9色では有意、白を固定した非白8色だけでは非有意」**の対比は一貫する。ただしこの結果だけで「9色集中の100%は白種選択の原因」とは証明できない。前のShannon連鎖律分解では9色差のうち24.1%が白対有色の2値成分、75.9%が有色割合で重み付けした8色成分だったため、**白種IDを固定すること自体が非白種の地理的重み付けを変える点**に注意する。

## 4．結論を論文でどう述べるか

**現時点で支持される最も狭く強い主張：**

> 現代GBIFに記録された植物相の写真由来9色の種組成は、属・種の分布域幅・粗い大地域親和性を条件としても、全球的には無作為に期待されるより色の集中が強い。一方、この集中には地理的不均一性があり、白色ラベル種を固定した条件で有色8色のみの追加的な色集中は明確ではない。

**未検証**：独立した花被器官の正解を持つ種別色、科属を超えた系統的独立性、WCVP厳格在来種に限定した新たな6地域帰無、実際の個体密度・開花バイオマス・訪花成功、温度・水分の因果選択、LGMレフュジア・適応。これらは観測された9色photo ROI proxyからは自動的に導けない。既存のWCVP strict在来属×分布域帰無p=.020は別の前解析であり、今回の地域条件付き検定の「在来再現」とは呼ばない。

### 次の焦点

地理的大区分をさらに細かくしてpを追うより、**測定過程の質をそろえた種群で主結果が保たれるか**を検証すべき。現時点の真正原画像QAでは花冠可視候補19枚中、数値ROIが有効なのは6枚で、13枚を同じFCPモデルでフル原画像に切り替えても1枚だけが回復。写真色分類を真正花弁色へ読み替えることが最大の推論上の制約。
