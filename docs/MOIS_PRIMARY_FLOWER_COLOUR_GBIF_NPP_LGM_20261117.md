# MOIS — 花色を主目的に戻したGBIF×NPP×LGM解析：結果・反証ゲート・論文化上の判定（2026-11-17）

## 研究の中心を明確にする

**主目的は全球植物花色（白／有色、探索的9色）が現代の生産力と古気候履歴にどう対応するか**。GBIFは現在の植物種分布、WCVPは地域別自生／外来、MODISは年間NPP・NDVI、ESAは木質地上バイオマス、WorldClimは現在と約22kaの気候を提供する。花色はGBIF自体で測定されておらず、MOIS原写真の9色ROIから作った**種別の暫定modal label**であり、開花花弁色の独立認証を完了していない。この限界を明記して花色の仮説を検証した。

これまでの「属のJaccard重複」「WCVP分類群分離」は、**花色と地理環境の見かけ上の相関が植物相の分類群構成の違いに由来しないか検査する補助分析**として扱う。分類群の入れ替わり自体を本論文の主目的へすり替えない。

## (A) 種単位：色ラベル白 vs 有色 × NPP・LGM・AGB・NDVI

NPP、有効LGM気候、BIO1/12、NDVI、ESA木質AGB、緯度、GBIF記録数、写真ラベルevidence状態が揃う**36,581種**。白と非白が同属に共存する**29,381種、2,365属**を属内中心化の線形確率モデルで比較、属cluster robust CI。種1行＝種重み、または各属の総重みを等しくする属重み。現在のGBIF占有100km格子における平均NPP・LGM以降気温変化を説明変数として使用。**これは同じ種の花色可塑性や進化速度の測定ではない。**

### 厳格な写真ラベル一致／NPP格子完全被覆

- 独立観測写真の色が一致した種だけでは、同属内白/非白の対比が**546種・88属**。種等重みNPP +0.897 pp, p=0.877、属等重みNPP −0.619 pp, p=0.929；LGM温暖化は+0.163 pp p=0.957／+2.716 pp p=0.589。両方とも**再現成功とは言えず、CIが広い**。この絞り込みでは木質AGB負係数が観察されたが小規模の事後探索であり独立検証を要す。
- NPPの有効格子が各種の現在GBIF生育格子の100%を占める比較では、20,123種・1,820属が白/非白の同属対比に残った。種等重みNPP +2.214 pp p=0.0198、属等重み+1.405 pp p=0.406。LGM温暖化は+1.235 pp p=0.0491／+2.296 pp p=0.0355。**NPPは属等重みで支持が安定しない**。

### 探索的9色モデル（属等重み・同時調整・9色BH）

- 白9色中、**LGM温暖化幅＋2.88pp/SD、未補正p=0.00330、BH q=0.0297**。
- 赤は**NPP −6.63pp/SD、未補正p=0.00442、BH q=0.0398**。

## (B) 地域単位：GBIFの現在植物相の白ラベル種割合

WCVPがその**広域TDWG3植物地理区でnative／introduced**と記載した種だけを厳格・緩和のいずれかに分類。各GBIF100km格子の存在種を1種1票で数え、元写真ラベルが白の種割合を応答変数にする。写真撮影地点の花色ではない。現在気候＋LGM気温/降水差＋NPP＋NDVI＋木質AGB＋緯度＋GBIF記録数＋属数ではなく各群の種数を調整、500kmブロック固定効果・同ブロックcluster robust SEで比較。

| 白ラベル種割合：500km地域内・各地域の格子を等重み（環境1SDあたりpp） | strict TDWG3 | moderate TDWG3 |
|---|---|---|
| **native群：NPP** | **−0.546**（7,201格子、p=0.0163） | −0.334（8,119格子、p=0.0972） |
| native群：LGM温暖化幅 | +0.532（p=0.117） | +0.250（p=0.415） |
| native群：NDVI | +1.035（p=0.000755） | +0.738（p=0.00555） |
| native群：木質AGB | +0.446（p=0.0282） | +0.479（p=0.00943） |
| introduced群：NPP | +0.122（3,110格子、p=0.730） | +0.013（3,606格子、p=0.963） |
| introduced群：LGM温暖化幅 | −1.832（p=0.00855） | −1.691（p=0.00869） |

- strict native群のNPPは種数重みで−0.196pp、p=0.227に変わり、**NPP効果は格子等重みに敏感**。
- native群のLGM温暖化幅は、地域固定効果／重み／区分を変えると有意性が変動。氷期からの気温変化に対する適応や祖先花色変化とは言わない。
- **種単位のNPPは正、native地域植物相では弱い負**という向きの違いは、それぞれの**推定対象（同属内の種形質 vs 格子内で観察される種プール組成）**が異なるため、必ずしも統計計算の矛盾ではない。

## (C) 種の花色を保ったまま属構成を差し引く：最も重要な反証ゲート

各属 `g` の全世界の受容種から得る**白写真ラベル種比率** `p_g` を1種1票で計算。現在GBIF格子 `c` にWCVP nativeまたはintroducedと記載された各属の種数 `n_{cg}` を集計：

`observed_white_c = Σ white_species/n_c`、`expected_from_genera_c = Σ n_{cg} p_g/n_c`、`within_genus_species_composition_c = observed_white_c − expected_from_genera_c`。

この分解は**同じ属に属する種の花色ラベルが地理的にどう入れ替わるか**の記述であり、**同じ種が花色を変えたことを示さない**。属の全球的な白ラベル率は同じ写真カタログから推定されているので独立した外部holdoutでもない。

**同一GBIF格子・説明変数・500km固定効果・cluster SE**で上記3つの目的変数を別々に推定し、環境係数が**小数点誤差2.2e-18以下**で加算再現することを確認した。

| NPPに対する白写真ラベル種割合の係数（pp/SD、500km） | strict native（7,201格子） | moderate native（8,119格子） |
|---|---|---|
| 観測の白ラベル割合 | **−0.546**（p=0.0163） | −0.334（p=0.0972） |
| **属の構成から予測される成分** | −0.340（p=0.0138） | −0.257（p=0.0338） |
| **共通属内の種構成による残差** | −0.207（p=0.217） | −0.077（p=0.618） |

| LGM温暖化幅に対する白割合係数（pp/SD、500km） | strict native | moderate native |
|---|---|---|
| 観測の白ラベル割合 | +0.532（p=0.117） | +0.250（p=0.415） |
| **属の構成から予測される成分** | +0.503（p=0.0311） | +0.496（p=0.0256） |
| **共通属内の種構成による残差** | +0.029（p=0.917） | −0.246（p=0.315） |

**nativeではNPP・LGMの地理的な白色割合との対応は、現地の属構成で大部分を再現でき、属内の種による独立差は確認されない**。NPP/木質AGB/NDVIの主要関連の重み依存と合わせると、現段階で「環境が白花を選択した」という結論は退ける。

introduced群でのLGM温暖化幅は、属内種構成残差と負の対応（strict **−1.457 pp/SD, p=0.00500**；moderate −1.327 pp p=0.00463）。1000km・種数重みの感度でも概ね負だが、導入過程・WCVP分類法・地域気候との交絡がある。**introducedの白花化／適応／レフュージアの因果証拠ではない**。nativeとの直接比較は格子サポートが異なるため、同一母集団に限定する必要がある。

## 生態学的主張の上限・次の優先順位

1. **支持される記述的事実**：写真から得た種別白/9色ラベルと、GBIF分布域NPP・LGM温暖化幅には種間の関連がある。現代のnative GBIF植物相における白ラベル割合と環境との関連は、大部分を属のプール構成で説明できる。
2. **未確認**：花色そのものの適応、同じ種内の変化、過去分布・氷期レフュージア、植物体バイオマスの花への投資、属構成だけでは説明できない頑健なnative環境選択。元の写真9色ROIには花以外の器官を拾う可能性があり、高確信度の種カタログが小さい。
3. **次の真正ゲート**：産地に確証のある在来種の花器官／花弁画像を独立に校正し、対象種を事前固定してGBIF分布・現在気候・NPP・LGM履歴との関連を**保留データ／分類群・空間ブロック外**で再検証する。レフュージアを論じるには花粉・化石・過去分布の独立資料が必須。

**論文化の主線は「全球の花色組成がどこまで現在環境と対応し、そのうちどこまでが分類群・地理的な種プールに由来するか」**であり、分類群だけを論文の目的へ置き換えない。
