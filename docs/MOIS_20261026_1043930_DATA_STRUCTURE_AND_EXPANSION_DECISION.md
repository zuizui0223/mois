# MOIS：104万枚のデータ構成から判断する追加取得の必要性（2026-10-26）

## 先に結論

**現在は無条件に追加100万枚／9,320万枚を同じROI手法で処理するより、既存の計測欠測・分類群の空白・写真の取得系列偏りを先に改善することを優先する。** ただし、全球・南北・極域・島嶼・季節を一般化するために*生物学的に有効なデータ*を増やすことは必要。最終的な93,209,351写真ID全部の一度の走査という工学目標は残すが、論文の証拠と計算規模を混同しない。

## 1. 元データの「母集団」を区別する

| 単位 | 検証済み |
|---|---:|
| 上流2026-09-27、適格写真ID | **93,209,351** |
| 上流の名目対象分類群（写真あり42,095） | **42,111** |
| 実際に画像処理を試行した元写真ID | **1,043,930** |
| 元4色自動分類成功 | **459,235** |
| 厳格な花ROI9成分の成功 | **390,541（全試行37.41%）** |
| 9成分が得られたが曖昧な画像 | 36,224（探索のみ） |
| 9成分なし（欠測、ROI失敗、旧4色のみを含む） | **617,165（59.12%）** |
| 4色はあるが9成分はない | **68,694** |
| 完全に9成分がなく元4色もない | **548,471** |

8・9色等の古いラベルから精密なLabや独立した緑花を推定しない。9成分の花領域ROIが本当の花弁の独立目視真値だとも扱わない。

## 2. 分類群の標本構成が最重要

実際の元写真IDと上流の**42,111分類群・93,209,351候補写真**のSHA固定されたcount rosterを照合。

- 厳格ROI9で色があるのは**21,227分類群、4,831名目属**。残る**20,884上流分類群**には厳格9成分の色がない（うち**16分類群は2026-09-27上流ソースに適格写真0**）。
- 有効9成分がある分類群の**中央値は3写真、90%点69写真**。**4,412分類群は1写真、8,511分類群は2–4写真、8,304分類群は5枚以上、5,278分類群は10枚以上、648分類群は100枚以上**。
- 9成分写真の分類群間の逆Simpson有効数は**約4,644**、属の同指標は**約515**。独立した進化系統数、写真の正解率や効果量の有効Nではない。
- 9成分画像数の上位1,000分類群が**32.49%**、一方93m上流写真機会の上位1,000分類群は**48.78%**。元画像の入手機会が多い植物への偏りは避け切れておらず、両者は異なる標本設計なので重み未復元では全球の真の白花割合にならない。

**「増やす場所」が見つかった。** 厳格9色がない20,884分類群のうち**6,205分類群は上流に100枚以上の写真候補**がある。その内訳は100–999枚で5,935分類群、1,000–9,999枚で270分類群。後者も含め、上流に十分な被写体候補があるため一律に写真を増やすのでなく、**失敗理由と保存済み旧4色を先に確認する**。

上流に候補があるが厳格9成分がない分類群の写真機会は合計**2,290,570枚（上流9,320万の約2.46%）**。残り約97.54%の上流画像は、少なくとも1枚の9成分色成功がある分類群に属する。これは分類群網羅性の観点では、全件走査で得られる**新しい分類群カバレッジの限界**を示す。一方、同種内の空間・季節・表現型の反復には大量画像が依然有用。

## 3. 20,884分類群の中身を追加診断した

[本物の画像試行ソースに基づく追加監査](https://github.com/zuizui0223/mois/actions/runs/40259190786)：

- 厳格9色が全くない20,884分類群にも**47,491枚の元写真処理試行**がある。うち**14,219枚**には元4色分類ラベルがあり、**10,515分類群**は少なくとも1件の元4色を持つ。
- 100枚以上の候補があり9成分0の**6,205分類群のうち3,396分類群（3,264+132）には元4色ラベルが残存**する。写真の別撮り直しよりも、既存の元ROIの数値列が別の原本に残るか検査する価値がある。ただし4色だけから9成分やCIELABを**捏造・復元できない**。
- 残る**2,809分類群**は「上流100枚以上・厳格9色0・元4色なし」。花ROI手法改善後の**新規有効分類群獲得の優先候補**。原画像があることと開花花弁が写っていることは別なので、有効な花写真を数枚盲検チェックする。

## 4. 「74,821分類群の処理済み」という数字には重要な注意

MOISの全1,043,930写真には、上流42,111名目分類群とは異なる**32,710分類群の元画像が各1枚**含まれている。合計**32,710写真**。**全て厳格9成分の色はない**。元4色は**11,451枚**に残っている。

これは同一写真IDが93m索引にも属するかどうかではなく、**元写真の分類群IDが、9,320万枚を定義した42,111分類群の名簿に存在しない**ということ。すべて**historical_main**の以前の取得コホート由来。内訳：ROI/flip gate失敗17,405、元4色成功のterminal記載10,150、terminal空欄4,096、曖昧847、画像取得失敗171、色パレット質量なし41。

**42,111分類群のカバー率と、別取得系列を含む74,821名目分類群の処理試行数は別物**。後者を世界の分類群網羅率に換算しない。この違いの原因（旧取得対象の範囲、学名/taxon IDの更新、eligible photo licensing）を別に検査し、全93mの追加ターゲット名簿を拡張すべきか科学的に判断する。

## 5. 取得系列で色が測れる確率が大きく違う

実写真IDをFCPの固定447,500件の元パケットと照合して厳格9成分計測成功率を計算：

| 真の元取得ソース | 元写真試行 | 9成分成功 | 成功率 |
|---|---:|---:|---:|
| FCP原100枚×4,475分類群 | 447,500 | 227,107 | **50.75%** |
| 大規模旧MOIS（FCPと一致しない） | 464,267 | 114,522 | **24.67%** |
| K1 元画像セット | 76,753 | 27,689 | **36.08%** |
| FCP5新規34,898等 | 確認済み | 残り | 群別source CSVで確認 |

FCPは元写真の**42.87%**だが厳格9色の**58.15%**。元写真の取得方法を制御せずに「全球平均」へ混ぜるとFCPの特定種・特徴を過大代表する。

FCPとMOISで**同じ元写真IDでも認定した分類群IDが2件不一致**。元のラベルは変えず provenance を保持する。

古いphoto lakeには元撮影者IDと各元ソースごとの厳密な抽出確率の全列は保全されていない。観察者数と確率重みの正しい補正をするなら、元93m observation metadataまたは測定workers側のsampling-provenanceを写真IDで復元する必要がある。

## 7. 今後の作業優先度（画像枚数増より先）

1. **ソース定義の確定**：42,111対74,821分類群の違い、32,710写真の地位、FCP/非FCPと元観察単位、源集合の有効9色数を分離。**ここは実際の写真を新規取得する必要がない**。
2. **ROI成功・失敗の偏りを修正する**：先に南半球熱帯、島嶼、低彩度・緑/茶花らしさ（葉・背景の混入に注意）、K1の46,288 ROI gate失敗などを独立目視でサンプルし、小規模な救済手法を比較。花の各器官を厳密分類する方式を全球9,320万件の前提に戻さない。
3. **ゼロ9色の6,205写真豊富分類群**を優先し、既存4色ラベルのみの3,396と4色すらない2,809を分け、最初に新しい厳格9成分が得られる効率を評価する。残る貴重な南半球熱帯・準極域・島/大陸同分類群、同年同月・同属/地域の反復を狙う。
4. **CIELABの真の写真画素測定**：新画像251枚では矩形box Lab vs 旧9色ROI白成分の差が平均36.2ポイントあった。花前景・領域選択の品質検証を実施してからL*/C*/h°を主な全球生物形質として使う。旧9成分からCIELABの数値を作らない。
5. **新しい大量画像取得**は上記の検証で、改善したROI方式が新しい**正しく測れた分類群/同じ分類群の島⇔大陸/南⇔北・季節の比較可能な対**をどれだけ増やせるか確認してから優先順位を決める。世界93m画像を1度走査する長期目標は残るが、ひたすら同じ品質の写真数を積んでも論文の主要な不足は埋まらない。
