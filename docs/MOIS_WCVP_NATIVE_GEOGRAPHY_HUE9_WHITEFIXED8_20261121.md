# MOIS：在来植物相の地理条件付き9色・白固定8色帰無モデル

更新日：2026-11-21。**計算・独立数値検証・GitHub Actions実行まで完了。**

## 1. 今回の結論と研究上の判断

**WCVP地域在来の記録植物相でも、属・現在の占有分布幅・粗い地理親和性を条件とした帰無に対して、写真9色の組成は集中している。南北の対比は残り、地理条件付きモデルでは白色種を固定した有色8色でも検出された。北極圏の独立した特徴を主要な発見として扱う根拠は、今回の条件では弱まった。**

1. **主結果として保持する：在来限定の9色集中。** 30種・100種基準、strict/moderate在来判定、6座標区分の等重みで同方向の結果が残る。
2. **地理的な主線として保持する：北半球でより強い集中。** 南−北の直接対比は9色のHolm補正後でも支持される。白固定8色でも地理条件付き帰無では対比が検出されるが、8色の属×幅だけの帰無では両側p=.110であり、帰無設計への依存を明記する。
3. **白固定8色の全球的な効果は条件を分けて扱う。** 非白30種以上の主標本は集中方向の弱い証拠にとどまり、6区分等重みでも明確でない。一方、非白100種以上の感度標本では集中が支持される。「有色8色には構造がない」「9色の結果はすべて白が説明する」とは結論しない。
4. **北極圏−北方温帯を主結論から外す。** 地理条件付き9色の直接対比は両側p=.246、Holm補正後p=.492。送粉・古気候・レフュージア機構の証拠として扱わない。

ここでの「集中」は、種数割合から計算したShannon多様度が帰無期待より低いことを指す。実際の花被色、個体数・花数の卓越、進化的な収斂を直接測定した結果ではない。

## 3. 地理的な構造：南北差は保持、北極の対比は弱まる

### 同じ置換内で計算した直接対比

対比の偏差は、地域AのShannon偏差−地域BのShannon偏差。南−北が正なら、北半球の方が帰無に対して強く集中する。同じ全球種ラベルの置換を全地域に適用し、地域間で共有する種による共分散を保った。

9色の北半球4,900格子は偏差−0.035057、南半球2,331格子は−0.000847。白固定8色では北3,840格子が−0.019939、南1,959格子が+0.007848。これらの平均の有意・非有意の違いではなく、表の**直接対比**を地域差の根拠にする。

白固定8色の南北差は、白色種IDとその分布を固定した地理条件付き帰無でも、有色カテゴリの地域的な組成に差があることを示す。ただし、属×幅だけの白固定8色帰無では偏差差+0.022024、両側p=.110。今回の強い南北対比は地理条件付き帰無の下での結果であり、すべての帰無設計に頑健だとは書かない。

## 4. 今回固定したデータ・方法と推論の限界

### 評価する植物相と交換する種プールを区別する

元のCOLXR/GBIF受容種37,104種、5,493,931種×100km格子、18,577格子を保持。WCVPへの一意な学名一致は36,762種。各格子25サブ点のうち20点以上が同じTDWG3コードに対応し、対応コードの混在がないstrict条件を使う。strict在来は34,781種・2,271,852種×格子、moderate在来は35,390種・2,604,870種×格子。moderateは独立再現ではなく重複する感度標本である。

今回、**評価する種×格子を在来に限定した**。色を交換する種プール、占有幅、地理親和性は比較可能性のため全GBIFに基づく。属×占有幅5帯（1、2–5、6–20、21–100、101以上）×地理親和性の中で、一つの種ラベルをその種の全格子へ同時に適用する。親和性は全占有格子の65%以上が一つの座標区分に入るかで定義し、それ以外は複数区分とする。

したがって、在来種だけの地域プール内で交換した解析ではない。在来部分集団の色別総数も固定しておらず、残差には在来種プール自体の写真色構成と局所的な共存構造の両方が含まれ得る。全GBIFから計算する分布幅・親和性には導入記録も含まれる。

9色の地理モデルでは全球の交換可能種20,760種、strict在来でその範囲に入る種19,860種、在来の種×格子の53.205%がラベル変更可能。白固定8色では全球7,667種、strict在来7,373種、非白在来種×格子の42.628%が変更可能。毎回必ずラベルが変わる割合ではない。

### p値と不確実性

9色seedは20261118、8色は20261118+803。各999回を結果に応じて延長・短縮せず完走。主仮説はstrict在来9色・30種以上における集中方向。下側pは `(1 + 帰無値<=観測値の回数) / 1000`、上側も同様、両側pは小さい尾の2倍（上限1）。浮動小数点の同値許容幅は1e-12。下側pの最小値は.001、両側は.002であり、表の.002をそれより小さいpとして解釈しない。

旧実装の模擬値だけの平均を中心とした両側pは、元数値との照合用の診断欄として残す。今回の主要pは順位型へ変更した。置換による検定は、指定した交換群に対する帰無の不変性を仮定する。[Hemerik & Goeman (2018), Exact testing with random permutations](https://doi.org/10.1007/s11749-017-0571-1)を方法上の参照とする。

帰無95%範囲は帰無統計量の分布であり、効果の信頼区間ではない。格子を独立な反復としてt検定するのではなく、種ラベルを全球同時に交換して空間的な共有を保持した。これはGBIFの観測偏りを解消する操作ではない。

### 残る科学的制約

- 色は写真由来のカテゴリであり、独立に認証された花被色ではない。WCVPの地域在来性も、個々のGBIF記録が野生の在来個体である証明ではない。
- 属は完全な系統制御ではなく、占有幅の帯は厳密な分布面積の一致ではない。6座標区分も正式な生物地理区ではない。
- 全植物相と在来限定で適格格子が異なる。今回、同じ格子の全植物相−在来の直接対比は実施しておらず、差を導入の因果効果と呼ばない。
- 送粉者、競争、環境フィルタリング、色素適応、レフュージアの機構を同定していない。今回の主張は、現代の記録植物相の写真色組成とその地域差についてである。

### 種単位とWCVP対応の監査

元の種ID73件がWCVP受容ID36件へ多対一で対応し、そのうち16受容IDには異なる写真色がある。strict在来の種×格子では、WCVP受容IDへ統合すると468行（0.0206%）が減り、影響する格子は447。これは元GBIFの同じ種IDの重複行ではなく、分類体系間の対応差である。自動的に色を統合せず、元の種単位を保持した。

元の30種基準の格子を固定し、対応先の各受容種に観測色のいずれか一つを残す場合、観測平均Hの変化は最大0.0001064。これは観測Hだけの範囲であり、統合後の帰無期待やp値の変化を拘束するものではない。仮に種数を統合し直すと適格格子は7,231から7,230になる。全監査数値は同梱JSONに保存した。
