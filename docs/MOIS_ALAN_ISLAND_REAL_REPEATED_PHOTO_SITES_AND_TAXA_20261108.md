# MOIS｜同一地点・同一植物分類群の年変化で光害との対応を追えるか（2026-11-08 JST）

## 現在地：全球の負の「空間」相関と、未確認の「年変化」を分離した

従前の2019・2021・2023・2024・2025年の真の写真白色ROI・同年VIIRS・同年WorldPop R2024B UCを再利用。元の厳格標本**7,982写真セル×年（島710）**における**全球の島×光害の空間交互作用 −2.497 [−3.949,−1.046]、名目p=.000802**はそのまま保存（[run 42363637615](https://github.com/zuizui0223/mois/actions/runs/42363637615)）。緩和標本**20,543セル×年（島2,026）**の全球値は−1.205 [−2.487,+0.077]、p=.0654。

**本検証はこれらとは異なる問い**：同じ0.05°地理セル・同じGSHHG陸塊IDを複数年にわたって真正写真で観測したとき、局所のVIIRS夜間光の年変化と白色ROI成分の年変化に島・本土差があるか。元写真ID・受理分類群ID・同年人口/VIIRS原ソースを再照合し、別の観察単位として推定した。夜間光を操作していないため、いずれも因果推定ではない。

### 2. 同じ地点でも、翌年の写真に同じ受理種が写るか

[同じ種の元写真を再集計する実測run 42389634418](https://github.com/zuizui0223/mois/actions/runs/42389634418) **SUCCESS**（source-signed aggregate artifact **13580952796**）。

WCVPの受理種名IDを、同一の0.05°セル×GSHHG陸塊×観測年の厳格ROI実測写真から得た。**同一地点に実際に写真のある隣り合う観測年**の植物種集合についてJaccard（交差種数／和集合種数）を求めた。各年の種の撮影が一時的・選択的なので**野外植物群集の真の入れ替わりや絶滅ではなく、写真で観測された種集合の重なり**を測定する。

| 隣接する実観測年ペア（同じ地点） | 厳格 | 拡張 |
| --- | ---: | ---: |
| 島の反復観測ペア数 | 185 | 532 |
| そのうち同じ受理種が1つも両年に写らないペア | **139（75.1%）** | **448（84.2%）** |
| 本土の反復観測ペア数 | 2,233 | 5,738 |
| 同じ受理種が両年に写らないペア | **1,541（69.0%）** | **4,717（82.2%）** |
| 島・本土それぞれのJaccard中央値 | **0** | **0** |

数値は**写真記録のJaccard**であり、真の種相のJaccardではない。撮影者や撮影季節、元写真機会、花の開花/分類精度が年で違うと、同じ地域で実際の植物群集が一定でも観測種集合は変わり得る。ここで示した高い「写真上の共通種ゼロ」は、同地点の群集白色ROI年差を遺伝的色変化として解釈できない具体的な理由となる。

### 3. 同じ受理種かつ同じ地点が複数年に写った場合

同一の受理分類群×0.05°地理セル×GSHHG陸塊で、**本物のstrict9元写真**が異なる観測年に最低2回あるときだけを採用した。受理分類群IDと場所の組を固定効果、暦年を固定効果、同年VIIRS・同年人口・写真努力を調整、5°地域クラスタ。これは同一個体でも同一遺伝子型でもない。

| 同種×同地点の真の反復記録 | 厳格 | 拡張 |
| --- | ---: | ---: |
| 繰り返し撮影された受理種×地点 | 1,257 | 1,756 |
| うち島の種×地点 | 68 | 124 |
| 島の独立陸塊（同種記録反復） | 10 | 22 |
| 同種×地点×年の実測記録 | 2,774 | 3,858 |
| うち島の同種×地点×年 | 147 | 264 |
| 島×光害の年変化係数（pp/log） | −2.099 | +9.806 |
| 名目95%CI | [−28.889,+24.690] | [−22.195,+41.807] |
| 名目p | .8764 | .5451 |

CIは非常に広く、両方とも明確な関連を示さない。母集団全体の種内生態応答を否定したわけではない。特に島の反復「種×地点」支持は厳格68単位しかない。写真月の一致、花器官の状態、地域個体群の同一性を確定できていないことが解釈範囲の限界。

### 研究上の現在の結論と次の主線

1. **保持する肯定的結果**：5年の同年・全球写真標本では、厳格標本の島×夜間光の空間的交互作用は負。元の分類群を均等に扱う真正ROI実測の観測パターンである。
2. **新しく実証した観測生態学的事実**：同じ地点を複数年再訪する写真標本は存在するが、隣接して撮影された年の受理種が1種も一致しないペアが島で約75–84%、本土で約69–82%。**写真上の観測種集合は非常に変動する**。
3. **未支持**：同じ地理セルで夜間光量が増減すれば、そこで花が白く/地味になるという年変化の予測。種も地点も同じ記録まで絞っても不確実で、光害の因果効果は言えない。
4. **次の真正データに基づく課題**：写真の観測月・開花段階を揃えられる反復地点の支持数をまず確認し、真の季節的な観測組成変化と、種構成の年差を混同しない。未観測種の白色や欠測年の衛星値は補わない。

元データ・写真ROI・厳格/拡張コホートは全て固定。用いた解析：`scripts/analysis/mois_island_ALAN_repeated_sites_photo_year_20261108.py` / `scripts/analysis/mois_island_ALAN_repeated_taxa_same_site_year_20261108.py`。対応する新規テスト2ファイルとActions workflow2件はPR #199のDraftブランチにあり、主線の既存実測論文結果を上書きしていない。mainは未変更。

## 4. 撮影季節の違いを元観測日で照合した追加実測（2026-11-08 JST）

[実際の元写真撮影月に基づく検証 run 42390436902](https://github.com/zuizui0223/mois/actions/runs/42390436902) **SUCCESS**、aggregate-only artifact **13580379660**。元の `historical_main`、真正strict9 ROI成功、WCVP accepted species IDを結合し、5年の源写真の撮影年月を利用。元のセル・陸塊・同年VIIRSと人口は全て従前SHA固定。日付から実際の月が取得できる元の受理種写真は厳格**39,864/39,864枚**、拡張**68,443/68,443枚**（今回対象とした真正strict9＋WCVP受理種の写真のみ）。不明月の補完0、仮想的な開花期推定0。

同じ0.05°セル×GSHHG陸塊に、写真がある**2つの連続する観測年**の観測種リストを比較し、年ごとに真のROI受理種写真が最多の「代表撮影月」が一致した場合と異なる場合に分ける（最多月の同数は暦月の小さい方を使用）。代表撮影月が異なっても、観測した複数の月が重なる年ペアについては**両年に実際に撮影されている同じ暦月の写真だけ**で受理種Jaccardを計算した。

| 記録上「共通する受理種が1つも両年に写らない」割合 | 全ての観測年ペア | 同じ代表撮影月 | 異なる代表撮影月 | 両年に共通撮影月が存在 |
| --- | ---: | ---: | ---: | ---: |
| 厳格・島 | 139/185 = **75.1%** | 16/27 = **59.3%** | 123/158 = **77.8%** | 113/153 = **73.9%** |
| 厳格・本土 | 1,541/2,233 = **69.0%** | 333/532 = **62.6%** | 1,208/1,701 = **71.0%** | 1,289/1,931 = **66.8%** |
| 拡張・島 | 448/532 = **84.2%** | 74/97 = **76.3%** | 374/435 = **86.0%** | 273/339 = **80.5%** |
| 拡張・本土 | 4,717/5,738 = **82.2%** | 1,042/1,337 = **77.9%** | 3,675/4,401 = **83.5%** | 3,116/3,991 = **78.1%** |

上表の「両年に共通撮影月が存在」はペアとしての共通写真月の有無で集計。共通月に絞った受理種集合そのものの**Jaccard中央値も島・本土・両基準ともゼロ**。すべて元の観測写真種集合の比較であり、写真から未確認の花期・現地植物相の真の交代を推定していない。

**生態学的解釈**：代表撮影月が一致するペアのほうが、異なるペアより写真に同じ受理種が再び記録される割合が高い。しかし、月一致の厳格島は**27ペア**のみ、拡張島も**97ペア**に限られ、撮影機会や観測者・植物分布の違いが同時に存在する。月を揃えたペアでも受理種がまったく再記録されない場合が多数あるため、**季節の違いだけで写真上の種リスト変動が消えるわけではない**。この資料は季節的な観測機会の重要性を示すが、植物個体群の真の変遷、昼夜送粉や光害の生物学的因果機構については未観測。

実装：`scripts/analysis/mois_island_ALAN_repeated_photo_month_match_20261108.py`、テスト `tests/test_mois_island_ALAN_repeated_photo_month_match_20261108.py`、Workflow `.github/workflows/mois-island-ALAN-repeat-source-month-photo-overlap.yml`。元写真の閲覧・追加ダウンロード・ROI再推論なし、外部サイトによる推測monthなし、却下されたMNAR tippingなし。
