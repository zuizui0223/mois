# MOIS：4色分類を9成分の連続色形質へ拡張し、未分類の本当の原因を分ける

**2026-10-25／実写真K1 76,753枚、原画像モデルの再実行なし、署名付き結果。**

## 結論と次の作業

- **花色の本表現は9成分の実測パレット組成とし、4色は既存研究との比較用に保持する。** (\mathrm{white, yellow, orange, red, pink, magenta, purple, blue, bronze}\) の \(flower\_fraction\_{}\) は、4色ラベルの情報を失う集約よりも連続的な色組成の地理・気候差を扱いやすい。ただし9色パレットは生の連続CIELABや花弁の光学反射スペクトルではない。
- **未分類解決の主目標はクラスター数を増やすことではなくROI・flip gateで落ちた46,288枚への独立した検出・花器官確認。** 単に近いクラスターを割り当てて、花弁が測定できたことにはしない。
- **比較用の4色、9色成分、探索的クラスターID、技術的欠測理由を別列で保持する。** 未分類画像を便宜的に非白色や白色に置換しない。

## 9色の探索的クラスタ数を原本で比較

カラーが元モデルにより分類済みの写真から、元写真IDのハッシュで最大16,000枚を訓練データとして選んだ。9色比率を合計1に正規化し、平方根変換した9次元（Hellinger組成空間）でMiniBatch K-meansを作成。座標、分類群、撮影者、気候、季節情報はクラスタ学習に用いず、固定の1,200写真でシルエットと乱数シード間ARIを計算した。元分類で曖昧な2,510枚は訓練に入れず、クラスタ中心への探索的な投影のみとした。

| 群数 k | シルエット | シード間ARI | 安定性ペナルティを含む評価 |
|---:|---:|---:|---:|
| 3 | 0.451 | 0.847 | 0.428 |
| **4** | **0.455** | **0.947** | **0.447** |
| 5 | 0.411 | 0.829 | 0.385 |
| 6 | 0.347 | 0.671 | 0.297 |
| 7 | 0.361 | 0.669 | 0.311 |
| 8 | 0.429 | 0.871 | 0.410 |

この**手法・K候補・標本に限れば k=4** が最も安定。既存4色ラベルを再現したかどうか、白花や有色花の進化上の最適状態が4個であるかは別問題。原4色ラベルと新クラスターは絶対に同一列で扱わない。

得られた4つの組成中心の主な色は、C01=白約93.4%、C02=桃約40.3%＋紫約16.4%＋白約17.9%、C03=ブロンズ約70.4%、C04=黄約85.3%。ブロンズクラスターは花弁の暗色化、周縁組織、枯れ／褐変、光とホワイトバランス、非花器官の混入のいずれとも現時点では断定できない。少数の元写真を検証するまで生物学的形質と命名しない。

## 次工程の順序

1. **実際の原画像で失敗原因を監査する。** ROI/flip gate の46,288件から地理・種・季節が一部に偏らないアウトカム非参照の監査画像群を固定し、「花が写っていない／花は写るが検出失敗／他の器官を検出／小花・複数花／反転・品質ゲート失敗」に人手で層別する。現状の status だけでは各原因を確定できない。
2. **ROI救済パイロットに限定して新モデルを試す。** 既存YOLO11+EfficientSAMは無改変でベースラインとして保持。Florence-2／GroundingDINO＋SAM2等の代替位置検出、複数花インスタンス切り出し、または花器官確認を並行評価する。元写真の再取得・追加推論が必要なのはこの段階だけであり、いきなり46,288枚全件に走らせない。
3. **真の連続色は別系列で取得する。** 写真で十分信頼できる花弁ROIのRGBから暫定CIELAB \(L^*,a^*,b^*,C^*,h^\circ\) を算出し、複数花色ならピクセル分布／割合を保持する。カメラ・照明・自動ホワイトバランスは色の物理的測定を歪めるので、色票なしのネット画像から真の色素含量・UV反射を主張しない。
4. **生態学解析は9成分の連続量と欠測機構を同時に扱う。** まず元分類済みだけの主解析と探索的曖昧2,510枚を加えた感度解析を分離し、属・地域・季節・撮影者、元写真選択確率、ROI可測性を考慮する。クラスタ比率だけで全球白花率や適応度を断定しない。
