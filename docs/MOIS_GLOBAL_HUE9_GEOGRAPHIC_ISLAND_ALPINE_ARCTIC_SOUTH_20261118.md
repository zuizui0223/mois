# MOIS：全球9色植物群集の島嶼・標高・北極圏・南半球勾配（2026-11-18）

## 実行済みの本解析

**真正MOIS 37,104受容種／36,758種の有効GBIFセル記録／5,493,931種×100km格子／18,577セル**を使い、9色Shannon多様度の「実測された種別写真色構成−属×種の占有格子幅を固定した199回全球帰無期待」を解析した。

地理情報：
- 島／大陸は先行MOISと**同じGSHHG 2.3.7高解像度L1原本**、ZIP SHA256 `8dbbe7e071e77e9e75f2d639239099ebca8d5c16d6a07df8169729d49f15cf41`。EPSG:6933 100km格子を3×3＝9点に分割。7/9点以上で**同一GSHHG sibling_id**に属する場合だけ大陸5 sibling（0,1,2,3,6）／島と分類。海・海岸混合・複数島は**未分類**。
- 2026-11-18の公式WorldClim 2.1現在標高10arcminute ZIP（SHA256 `6a9f4e9a37f289d594ed1567b63be344a4dacf247f0b69756e81df031087e3bd`）と内部単一GeoTIFF（SHA256 `b89becfdece8b61f4c28ea779e4a979d6729672dd99e870c8732026d5a9823aa`）。同じ9個の陸上サンプル点の中央値を100kmセルの**地形的標高**と定義。これは花の撮影地点の標高や厳密な高山帯の同定ではない。
- 北極圏：北緯66.562°以上という天文学的緯度帯であり、厳密な植生Arctic biomeや真のトナカイ苔植生境界ではない。南半球：緯度<0、南北中緯度は絶対緯度30–55度。

真正原本をSHA固定し、**199回すべての全球・属×占有幅条件付き種写真色ラベルシャッフルを元のseedでそのまま再現**。格子数30種以上の12,728セルに限定した主集計も元PR #206の帰無期待と全格子で一致した。各グループの統計は、全世界の同じ種の色ラベルを一度だけ入れ替え、その種が現れる全格子を同時更新した**全球置換**により算出。隣接格子を独立な1万件のサンプルとしてpを計算していない。

## 2. 生態学的な読み取り

**島嶼：**9色の地域植物相の白ラベル平均は島66.47%、大陸62.48%（**差+3.99pp**）だが、**属×種分布幅で期待される色構成からの9色Shannon偏差は両群ほぼ同じ**（−0.02989対−0.03127、偏差差+0.00138、p=.935）。よって「島では9色全体が普遍的に単純化」という主張は未支持。島分類可能418セルのうち、**面積10万km²以上の巨大島が355セル**と大半を占める。最も隔離された小島・小面積島が多数欠けるため、島嶼シンドローム仮説全体を否定する結果でもない。ユーザーの既存「島」研究の小島データの独立照合が重要。

**高標高：**100km格子の平均陸地標高1,500m以上では白色ラベルが61.50%と低標高63.55%より低い。極高標高2,500m以上は61.18%。高標高セルのShannon偏差は負に大きいが、高−低直接差はp=.235で支持が明確でない。古いMOISの別313,535写真・4色データで高標高の白写真比率低下を報告していたことと方向が一致するが、元写真の標高とGBIF種分布格子の標高は別の推定対象。気候・標高・植生・種プールの交絡はなお残る。

**北極：**Arctic circle上での白ラベルは67.04%で全球平均63.13%より高く、**単純な「極地で白花が減る」現象とは異なる**。だが9色Shannon偏差は+0.02346（p=.580）で、北極圏は帰無期待より強い色集中が確認されない。50–66.562Nでは−0.04208で、北極と北方温帯の差はp=.05と境界的。光環境やマルハナバチの不足を直接測ったわけではない。

**南半球：**南半球では白ラベル59.48%で北半球64.67%より低く、9色Shannon偏差も**−0.01306対−0.03823**と色集中が弱い方向（全球置換で差p=.020）。しかし同じ絶対緯度30–55°同士の南北比較ではp=.085なので、北南の気候分布・種数と大陸植物相の構成に敏感。送粉者ギルドの違い・人為導入や観察バイアスが代替説明。

## 3. 明確な限界・次段階

- **画像で正しい花被器官を独立認証した9色ではない**。緑・褐色の葉・苞・背景による色ラベル誤認、開花状態、撮影努力が残る。9色の見た目をUV・色素投資・受粉成功とは読み替えない。
- **GBIF種×格子1種1票**は現地の花の量、個体数、開花期・送粉機能を表さない。
- **島の100km判定は巨大小島を十分に解像しない。**島の種プール構成と島面積・隔離度は別途真正Islandリポジトリの島単位に戻って比較する。
- **北極圏・高山・南半球を同じ送粉者希少性という生態因子として束ねない。**各地の送粉者ギルド、温度・降水・日射、植物群集・系統プールの条件が違う。
- **WCVP nativeをTDWG3地域内で限定する別の感度**、気候・NPP・AGBの共変量調整、5°近隣山地ペア、南北同緯度・同気候保留は今後の別工程。未実行のものを「確認済み」と記載しない。
- これらのグループ別効果と南北・島・高度比較は事後の複数の地理的探索を含み、いまのp値は未補正。
