# MOIS：最新の実測1,043,930枚による湿潤・高標高・島・季節の再解析

**2026年10月25日19:30 JST以降の再解析。旧350,399枚の結果を再掲したものではない。**

## 1. 完了した最新データ

- iNaturalist原本写真の実測画像処理 **1,043,930枚（photo_id重複なし）**。FCP5は **35/35グループすべての画像ROI処理を署名付きParquetで照合した**。技術的不明は584,695枚で、そのままunknownに残す。
- 元の固定YOLO11/EfficientSAM ROI-v4による4色成功 **459,235枚**（白219,600、黄橙146,896、赤桃47,987、青紫44,752）。分類できた写真内の白色47.819%。これは全開花個体での白花率ではない。
- 日付を持つ写真 **1,043,911枚**、有効座標を持つ写真 **1,043,735枚**。
- 既存350,399写真IDの年気候値を完全保持し、未結合の**693,531実写真ID**でWorldClim 2.1 BIO5/12/14、月別VAPR/SRAD、標高DEMを再サンプル。合計**1,041,051件の気候完備写真、うち4色分類458,174枚**を得た。
- 実際のGSHHG2.3.7高分解能海岸線を使い、既存313,535枚の島嶼区分をSHA確認して保持し、残る写真を正式に点→陸塊分類。島137,076枚、大陸886,151枚、未割当20,703枚を区別。
- **原画像の新規ダウンロードや色再推論はこの再解析でゼロ**。全93,209,351件の未計測元データIDを誤って画像計測済みとはしていない。

## 2. 最新データでの結果と前回35万枚との比較

| 環境・推定量 | 35万枚の以前の点推定 | **最新104万枚の点推定** | 最新95%区間 |
|---|---:|---:|---:|
| 大気中水蒸気（属×5°地域×取得系列内） | 白率+5.03 pp/環境SD | **+4.18** | [+2.31, +5.72] |
| 年降水量（同条件） | +1.49 pp/SD | **+0.69** | [−0.56, +1.92] |
| 標高（同条件） | −2.50 pp/SD | **−2.44** | [−3.53, −1.06] |
| 同一陸塊5°近接高地(≥1,500m) −低地(<500m) | −5.09 pp、44近接地域 | **−5.23**、58近接地域 | [−8.32, −2.13] |
| 島−大陸（環境・地域を最適マッチ） | +1.40 pp、102ペア | **−0.89**、315ペア | [−2.59, +0.81] |

**重要：旧と新は地理・属と取得系列の支持数や重みが変わる。係数差は時間的な生物学的変化や独立した外部再現を意味しない。**

### 湿潤・乾燥

5°の分類群セル内比較では、実データ源×属×地理をそろえた大気中水蒸気量の白花ラベル正勾配が、35万から104万へデータを増やしても **+5.03 → +4.18 pp/SD** と正に残る。年降水量は **+1.49 → +0.69** と弱まり、区間がゼロを含む。

温度・水蒸気・降水・日射・標高を**同時**に調整すると、水蒸気量係数は **+0.81 pp/SD [−1.51,+3.29]**、標高は **−1.61 [−3.35,+0.08]**、降水は **+0.96 [−0.28,+2.12]** となり、区間がいずれもゼロを含む。これは湿度単独の因果効果を確定したというより、共通した熱水分・地理勾配に花色組成が対応している、と読むべき結果である。

5°属×地域×取得系列内の勾配推定は **75,928分類群セル・265,527分類済み写真** の比較可能な層で行われた。世界の459,235分類済み写真をすべて独立な回帰反復として扱っていない。

### 標高

属×地域内の標高負勾配は **−2.44 pp/SD [−3.53,−1.06]**。別分析で同一陸塊の近接5°内に低地(<500m)と高地(≥1,500m)を持つ **58地域** を集めた場合、低地白率48.19%、高地42.96%、高地−低地 **−5.23 pp [−8.32,−2.13]**。58中42近接地域で高地側の白が少ない。標高での有色花相対優位は継続して確認されるが、温度/水分/紫外線/送粉者の選択メカニズム自体は未確定。

### 島嶼性

最新写真の生の白ラベル率は**島52.64%、大陸47.16%**、島−大陸 **+5.48 pp**。しかし同一粗地理帯内で気候・日射・標高を条件づけた回帰では **−0.47 pp** に反転。環境の重なりと1:1条件を要求した**315ペア**では **−0.89 pp [−2.59,+0.81]**、ゼロを含む。前回は単純+4.22、調整+3.16、102マッチペア+1.40 pp。島で白花が多いという写真単純集計を「島固有の適応法則」とみなすことは、最新データでさらに難しくなった。環境マッチした島/大陸は同一植物種とは限らず、島ごとの在来性、系統、送粉者は未調整。

### 季節

温帯側の観察日から定義した夏−冬白ラベル率は、北半球 **+1.49 pp（前回+2.83）**、南半球 **+8.43 pp（前回+10.50）**。分類済み写真は北夏143,993／北冬16,430、南夏19,240／南冬13,920。南半球の**共通種の相対撮影頻度の寄与 +5.82 pp**、北半球でも +5.22 pp。同じ写真の種構成が結果に影響する。個体内色変化、当該年の天候による色素応答ではない。

## 3. 極めて重要：4色分類の欠測は環境に依存する

前回の「ROI/flip gateが約60%落ちる」の問題は、新しい104万枚でも継続。全体で**4色成功43.99%、unknown56.01%**。

- 島：分類成功 **41.03%**、大陸 **44.52%**。
- 北夏 **47.83%**、北冬 **37.64%**。南夏 **41.95%**、南冬 **37.12%**。
- 大気水蒸気量の最乾燥20%では **47.68%** 成功、最湿潤20%では **39.82%** 成功。
- 低地<500mで **43.62%**、高地≥2,500mで **47.76%** 成功。

したがって、白花ラベル割合は「写真にある花色」の無作為な欠測ではなく、分類可能な写真が環境・場所・季節で選ばれる可能性がある。unknownを白/非白と置換した生態学的な断定は避ける。全体でunknown全部が非白なら観測白/全写真下限21.04%、全部白なら上限77.04%という極端な境界になり、写真だけから全開花個体群の白色率は識別できない。この感度の大きさはデータの量だけで消えない。

## 4. 論文としての新しい主張

**「世界の自動計測可視花色の地理的構成は、大気水分・標高の勾配と対応し、地域・属・撮影系列の比較でも一部の関係は残る。しかし、島で白花が多いという生の差は環境マッチング後に消失し、季節差は写真に現れる種の撮影構成に強く依存する。さらに写真の4色分類可否自体が環境・地理・季節に偏る。」**

これが現時点で最も実測根拠が広く、過剰な適応説明を避けたマクロ生態学的な結論。特定の色素コスト、送粉者選択、進化的収斂、島の在来個体群の白色化の証拠ではない。
