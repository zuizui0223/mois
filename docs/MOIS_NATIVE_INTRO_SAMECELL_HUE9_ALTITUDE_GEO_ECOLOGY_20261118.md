# MOIS：全球9色の群集集中 — 在来種と導入種を同じ格子で比較し、高標高・島・南北差を検証（2026-11-18）

## 現在地

元MOISの37,104受容種写真9色ラベルから作った**全球5,493,931種×100km GBIF格子、18,577実格子**と、Kew WCVPのTDWG3「native / introduced」地域分布判定を利用。**両statusが各30種以上存在する実際に同じ100km格子**で、既存の属×種占有格子幅条件付き199回全球色ラベル置換からのShannon偏差を直接比較した。

目的変数は、`Δ = (H9_native−E_null,native) − (H9_introduced−E_null,introduced)`。**Δが正なら、同じ格子で導入種群の写真9色が在来種群より相対的に集中**することを意味する。このデータの写真色は実花被色の独立認証ではなく、地理は現代GBIF記録、nativeは広域TDWG3判定である。

### 真正データと母集団

- 原WCVP×GSHHG島／大陸×WorldClim2.1標高の出典を正規化したsigned artifact ZIP SHA256 **`cbe1eef381e3e1a0062dbf5134b047f947338b7c499d2ecc0cd22ee8855909fd`**。内部2数値出力のSHAも照合。
- strict：**3,106同一格子・464個500km空間ブロック**。moderate：**3,602格子・507ブロック**。各群最低30種。
- strictで両群最低100種を要求すると1,299格子・264ブロック。moderateは1,556格子・298ブロック。strict/moderateは同じ元データの重複した地理的感度分析であり独立再現ではない。
- 色の分子単位、花被ピクセル、各種の野生個体数や送粉者の訪花頻度は測定していない。

## 1. 同一格子の在来−導入9色Shannon偏差

500km空間ブロックを復元抽出する**20,000回cluster bootstrap**。2つのstatusは常に同じ格子でペア保持した。帰無期待値は元199回の大域的色置換の平均に固定するため、bootstrap区間にはそのMonte Carlo誤差を新たに伝播していない。

| 同じ格子のShannon偏差、native−introduced | 格子等重み | 両statusの少数群種数による重み |
|---|---|---|
| strict、各30種以上・3,106格子 | **+0.03994** [95%CI +0.02837,+0.05166] | +0.00557 [−0.00754,+0.01965] |
| moderate、各30種以上・3,602格子 | **+0.03928** [+0.02863,+0.05035] | +0.00429 [−0.00820,+0.01754] |
| strict、各100種以上・1,299格子 | +0.00681 [−0.00674,+0.02081] | −0.01430 [−0.02842,+0.00072] |
| moderate、各100種以上・1,556格子 | +0.00615 [−0.00612,+0.01914] | −0.01468 [−0.02826,−0.00037] |

**結論：全球平均で導入種群の色が強く集中する、という効果は支持種数で重みを変えると消える。** これは先行した「在来−導入の白写真色種率の差が種プール規模に敏感」の結果と整合する。導入による進化的色彩選択と同定したわけではない。

厳格判定3,106格子の同一格子平均では、native観測−帰無**−0.04538**、introduced **−0.08532**。native白写真色平均**62.570%**、introduced **65.547%**。

## 2. 高標高では差が拡大：近隣500km空間ブロックに限定しても残る

strict、両群30種以上の同一格子：

| altitude bin | n格子 | native白率 | introduced白率 | native−introduced Shannon偏差 |
|---|---:|---:|---:|---:|
| 低標高500m未満 | 1,863 | 63.450% | 64.304% | **+0.0104** |
| 高標高1500m以上 | 337 | 60.300% | 69.841% | **+0.1494** |

高標高−低標高のΔ差 **+0.13894 Shannon** [95%CI +0.10694,+0.16631]。両地域を含む空間ブロックだけに限定し、**35個の500kmブロックそれぞれを1票として比較**しても **+0.07315** [95%CI +0.02297,+0.12221]。両statusの少数種数による重みを掛けると**+0.06412** [95%CI +0.01709,+0.11023]。moderateでも共有40ブロック**+0.08020** [+0.03317,+0.12484]、種数加重+0.07522 [+0.03087,+0.11691]。**直接の地理高低比較において導入種群のより強い色集中が見られる**、という記述的生態学的結果はこの設計では保持される。

ただし格子中央値標高は**WorldClim2.1標高の100km格子内陸上9点の中央値**で、個々の植物・花の標高とは違う。高地で導入種が白ラベル優占しやすい場合も、写真器官の観測バイアス・導入・園芸種の選別・群集の異なる成り立ちを分離できていない。

## 3. 500km空間固定効果で現在気候・生産力・LGMを調整するとどうなるか

前のsigned [気候・植生・NPP・LGM 100kmグリッド成果物](https://github.com/zuizui0223/mois/actions/runs/44236695589)と全く同じ格子を結合し、気候が揃ったstrict **3,106格子**に500kmブロックfixed effectsを適用（ブロック内変動のある**3,016格子／374ブロック**で推定）。

応答は同一格子Δ、説明変数の標高は1km当たり。ステップごとに同じ標本で以下を比較：

| モデル（strict,各30種以上、セル等重み） | 標高+1kmに対するΔShannon係数 [cluster CI] | p |
|---|---|---|
| 標高＋緯度＋両status種数＋島/大陸のみ | **+0.04442** [+0.02871,+0.06012] | 2.99e−8 |
| 上記＋現在温度・降水・NPP・NDVI・木質AGB | +0.01113 [−0.01742,+0.03969] | .445 |
| 上記＋LGMからの気温・降水差 | +0.00559 [−0.02197,+0.03315] | .691 |
| 全調整＋status少数群種数のセル重み | +0.01879 [−0.00360,+0.04119] | .100 |
| 全調整・標高≥1500mダミー | +0.02043 [−0.00585,+0.04671] | .128 |

**標高そのものの独立した効果は、一次のstrict・等セル重み・全気候調整では支持できない。** ただし重み付けやWCVP地理割当を変えると一部のモデルでは正方向の95%区間がゼロを含まず、完全な否定でもない。

- moderate・各30種の全調整等セルでは+0.01431/km（p=.256）、少数status種数重みでは+0.02678/km（p=.00855）。
- strict・各100種の全調整等セルでは+0.01982/km（p=.219）、少数status種数重みでは+0.02759/km（p=.0337）。
- 1000km空間固定効果・高標高ダミー・白色割合調整の診断もsigned係数CSVに保存。これらは事後的な複数感度で、選んだ有意な係数を因果・汎化可能な機構と見なさない。

現在気温はstrict全調整でβ−0.0677/SD（nominal p=.0054）、LGM気温差−0.0360（p=.0214）、LGM降水差−0.0162（p=.0115）。だが気候と標高の共線性・年代差・多重探索の未補正pから「どの気候因子が色素選択したか」は確証できない。NPPの独立係数はstrict全調整でp=.804。写真9色は植物の生産・送粉量ではない。

## 4. 島・北極・南半球の比較可能性

**島嶼**：同じ格子で両群各30種のstrictは島159セル・56個500kmブロック、大陸2937セル。native−introduced Δは島+0.0181・大陸+0.0412、島−大陸偏差差−0.0230 [−0.0619,+0.0205]でゼロを含む。**大陸と島が共存する500kmブロックは6個**で、信頼できる地域内ペア解析には不足。100km判定は極小島を識別できず、巨大島に偏る。島嶼の送粉者不足による一律白花化は立証できない。

**北極圏**：WCVP strictで両statusが各30種以上の北極圏セルは**12格子・4ブロック**、moderateでも15格子。北極−北方温帯のnative-introduced同一セル効果を、このデータから定量的に検証する設計は不足。nativeのみの北極341格子の帰無結果は別の推定対象としてPRに保持する。

**南半球**：strictで両status30種以上の915格子、北半球2191格子。Δは南+0.0457/北+0.0376。島などの地理的非対称性を残したままの大域差は空間bootstrapでCIがゼロを含む（差+0.00810 [−0.01349,+0.02982]）。少数status種数重みでは南北差+0.0328 [+.00845,+.05687]が残るが、同じ500kmブロックに南北両側を含むものはない。地理・種プール構成への非独立性を断った結果ではない。

**主線としての科学的な結論：** 群集9色の非無作為な集中は現代の在来/導入植物相において同じ地理でも異なり、**高地と低地で差の大きさが変わる**。ただしその変化は現在気候と強く交絡し、導入された花が高度に適応して白化した直接証拠ではない。次に必要な独立検証は「同じ属×原産域×地理ブロックで導入候補種を比べる」ことや実花色・送粉ギルド情報であり、現在は写真ROIの種ラベルに限る。
