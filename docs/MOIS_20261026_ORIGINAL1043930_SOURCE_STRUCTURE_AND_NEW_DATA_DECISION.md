# MOIS：実測104万枚のデータ構成監査と「増やすべきか」の判断（2026-10-26）

## 結論

**一般的な「さらに何十万枚増やす」段階ではない。元の9,320万件を計測可能にする全件走査基盤は維持しつつ、短期的には (a) 有効9成分ゼロの分類群、(b) ROIの失敗原因、(c) 南半球・熱帯・島嶼の偏りを先に補完するべき。**

今回、2026-09-27 のフル源データ42,111分類群/93,209,351原写真候補と、1,043,930 unique 元写真IDの実測台帳、その保存済みROI9、FCPの実測原本447,500枚、GSHHG陸塊、観察IDを**ソース別SHAと厳格な写真ID結合で実監査**した。元画像の追加ダウンロード・再推論0。リリース実体とは別の地域・分類群・ROIの盲点を特定した。

追加の写真がない約90万件でも研究データの分母と欠測として残すこと。9色ROIは花弁・萼など器官別の真の色ではなく検出した花領域の画素分布であり、緑が独立成分として入っていない。真のsRGB由来CIELAB L*/C*/h°は251枚の別パイロットで確認したにとどまる。

## 2. どの分類群に写真が偏っているか

**いま厳格ROI9が10枚以上あるのは5,278分類群（母集団42,111の12.53%）だが、ここに**厳格ROI9の**343,296枚（87.90%）**が集中している。残りの15,949分類群の有効9成分は47,245枚だけ。

元源候補写真も、上位1,000分類群に48.78%の写真が集中しているが、これをそのまま「全球の種間比較で豊富に観察された植物が重い」計量とするのは避ける。追加情報の独立単位は画像枚数、観察ID、分類群、地域×季節で違う。

厳格9成分の写真は**895,666の一意元観察ID**とは異なる（これは全104万写真の一意観察ID数）。実際、**225,970枚の元写真IDは合計77,706の複数写真付き観察に属する**。同じ観察の写真を独立な開花個体として数えない。元観察日が適切に取得されている原写真は1,043,911件。

## 3. 元9,320万候補を使った分類群別追加取得優先度

| 写真の元源条件 | 分類群数 | 9成分取得の状況 | 当面の処理判断 |
|---|---:|---|---|
| 候補写真ゼロ | 16 | すべて9成分なし | 同じ源からは補完不能。ソース更新・分類群照合が別途必要 |
| 候補写真1–9、9成分ゼロ | **3,050** | 少数しか元写真がない | 既存候補を極力漏れなく評価、非花器官混入の手動点検 |
| 候補写真10以上、9成分ゼロ | **17,818** | 源に2,275,692の候補元写真あり | まず独立観察の候補写真・ROI再確認、必要な新画像を選択 |
| 9成分取得1–4枚 | **12,923** | 属×環境/季節の反復が不足 | 独立観察・地域・月を広げる |
| 9成分取得5–9枚 | **3,026** | 観察反復はまだ薄い | 代表性を見て優先度調整 |
| 9成分取得10枚以上 | **5,278** | 343,296枚あり | 当面むやみに増やさない |

**9成分ゼロの20,868分類群で、元データに写真が存在するものは合計2,290,570候補画像を持つ（全9,320万の2.46%）**。したがって、全球の分類群カバレッジを実質的に改善する第一段階は、**全9,320万件より2.29m候補の範囲**に絞って画像選択する価値がある。もちろん全件走査する最終スコープからその他を削除する意味ではない。

有効9成分がない20,884分類群のうち**12,108分類群（58.0%）は写真を1枚しか処理していない**。一方で**1,935分類群は5枚以上、574分類群は10枚以上処理しても9成分ゼロ**であり、画像追加だけではROI失敗が解消しないリスクがある。

### 2.29m候補からの実際の実装可能な最初のステップ

- 全20,868候補あり・9成分ゼロ分類群から各3枚までの**候補スロット数**は61,585（稀少分類群1–9枚の3,050分類群が8,131候補、10枚以上の17,818分類群が53,454候補）。これは**新規ダウンロード枚数でも、データベースから実際に確定した一意の画像IDリストでもない**。
- 元ソースにある全写真IDと観察UUIDで選択し、**同じ元観察に属する複数写真を控え、既に104万枚に含まれる写真IDを除外**する。候補不足は明示する。
- 開花器官の確実性を従来の4色分類と同一視せず、白/緑/褐色を色によって撮影候補から除外しない。
- 緯度（特に南熱帯・南温帯・北極）、地理・陸塊、季節を事前に層別して、登録種カバレッジだけ改善して同じ北温帯へ集中することを避ける。具体的な写真ID抽出には署名済み93m全写真メタデータが必要。

## 5. 元の4色画像と9成分の落ち方が異なる

元のFCP 4,475分類群×100画像=447,500枚は**ROI9が227,107枚（50.75%）**ある。他方、歴史的mainからFCP447,500を除いた464,267枚では**元の4色成功183,216枚**に対し**保存された9成分は114,522枚（24.67%）**。**68,694枚は元の4色が判定済みでも9成分が現行の元Parquetにない**。これは単なる画像が撮れない問題だけではなく、旧中間ファイルで連続色情報が失われた問題でもある。可能なら中間ファイルの再復元を先に試み、新しい画像取得で埋めようとしない。

32,710枚は現行2026-09-27フル42,111分類群のtaxon ID集合に属さない古い源の実測写真（すべてhistory-main）。**うち11,451枚は旧4色ラベルありだが9成分はゼロ**。古い別sourceで対象になっていても、2026-09-27の現行42,111元画像索引には属さない。個体同定誤り・分類学改訂などをすぐ断定せず、古い出典と母集団定義を区別して保持する。FCPの同一写真について原受理taxonがMOISと異なる例も2件ある。

観察者IDと元の写真選択確率は、最終の104万枚統合表には入っていない。したがって、現行104万を単純IPWで「全93mの代表的開花植物」に戻すことは不可能。ソースアーム別の元観察UUID・撮影者・取得確率は本来の署名済み原索引に戻して復元・記録すべき。

### 科学的な判断

湿度・標高と白色成分の符号がすでに出ているので、それを単にサンプルサイズ倍増で有意にしに行く段階ではない。**未観測分類群・南半球と熱帯のROI偏り・同じ観察内の画像反復を改善し、既存の正の勾配が一般化できるか**を優先する。

この監査を超えて全球の種群集を代表するには、元42kの分類群可用性だけでなく、地理×季節×撮影者の機会数と独立な真の花領域検証を追加することが条件。9色元Parquetと元写真のSHAは変更しない。
