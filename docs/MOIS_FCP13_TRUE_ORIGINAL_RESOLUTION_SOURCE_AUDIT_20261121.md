## 成果：モデルは同一、元原画像のSHAは13/13一致、しかし12/13は依然技術的に分類不能

2026-11-20の真正「開花注記付き原写真46枚」から、440px予備目視で花被候補とした19枚を凍結FCP YOLO11/EfficientSAM ROI-v4で`/large`版として計測した結果は、数値ROI有効6枚・技術的不明13枚。今回この**同じ13写真**を`/original`実画像バイトで再計測した。

**[再実行 Actions #44838300475](https://github.com/zuizui0223/mois/actions/runs/44838300475) SUCCESS**。数値artifact **#14679264010**、ZIP SHA256 `042cfe9e3be17d5b214c65659d65c98d53a519fcb152260e685c0cd989e71f0e`。ZIP内では13写真のフル原画像バイトSHA・写真ID・観察UUID・ライセンスを以前の真正46写真ソースと照合し、**13枚すべて完全一致**。ダウンロード失敗ゼロ。

元画像実測の結果、**追加で9成分の数値を得られたのは1枚のみ**。厳格な写真9色単色ラベルを新たに得られたのは**0枚**。処理できた画像バイト13/13、元JPEGの既存SHA一致13/13、凍結FCPモデル同一（検出器、SAM encoder/decoder、計測ソースblob、閾値）、元データの重複再利用なし。

**今回の1枚**：*Hedysarum hedysaroides*、photo ID `699083444`。元`/large`では反転マスク不安定、フル`/original`ではFCP四状態`yellow_orange`に通過したが、実9成分はbronze=0.5474、white=0.3583、pink=0.0674、yellow=0.0269で、単色9色条件（最大0.60以上、次点との差0.20以上）に達しない。したがって**「黄色・橙花と確定」ではない**。既存の予備写真目視との色の不整合は、花被以外の器官や背景のマスク混入などの追加検証対象。

原縮小版の失敗13枚には、花が見える予備画像にもかかわらず花ROIマスク不検出、向きによる抽出領域の変化、複色・写真背景の混入などが含まれ、**撮影画像解像度の低さだけで失敗を説明できない**。ただし同じ13枚でのペア再測定であって、13種・独立地域の反復でも、画像品質一般の因果的効果の実験でもない。

### 再現性・ゲートの失敗と修正

最初のCI [#44837867323](https://github.com/zuizui0223/mois/actions/runs/44837867323) は`/original.jpg`を直接FCP既定画像取得関数に渡したため入力URL検査で失敗。凍結FCPの元`image_loader`は`/large.jpg`のみ許可する。これは種、画像欠損、モデル色結果の失敗ではない。

修正ではFCP `run_batch`に元から用意された`loader`注入引数を使い、**凍結FCP評価ソース・YOLO11/EfficientSAM重み・厳格閾値を一切変更せず**、`/original`バイトを取得する明示的なローダーだけを導入。S3 host、photo ID、`/original`URL、12 MiB上限、画像デコード、FCP標準と同じ全HTTP試行の共有rate gate、SHA256を厳格に検証。CIは画像SHAが以前の46枚ソースから取得したものと1つでも異なる場合停止。修正後の独立監査で13/13一致。

- 実行コード：`scripts/acquisition/mois_FCP13_original_resolution_retest_20261121.py`
- CI：`.github/workflows/mois-20261121-fcp13-true-original-resolution-gate.yml`
- 永続化した数値：[13枚の元・縮小ペアCSV](../analysis_specs/MOIS_FCP13_TRUE_ORIGINAL_vs_LARGE_PAIRED_RETEST_20261121.csv)、SHA256 `4d44621f49d4bdc39077c52c54a4fcb23411f722c381da3305f393cb40b162c7`
- 配布データはすべて暫定ROIの検査証拠で、真正花被器官の独立アノテーションでも種色の確定でもない。**元MOIS種9色カタログは不変**、PR #200未マージ・`main`未変更。

### 次の研究上の判断

**全13枚に対して凍結モデルの閾値を緩めて「花色」を水増ししない。** 花マスク失敗は原画像で花被の位置を独立に特定してから検出器の原因を区別し、反転不安定は別器官へのマスク飛びを確認、色組成曖昧は真の複色・雄しべ・苞・背景を分離して人手確認する。その上で必要なら別の器官専用セグメンテーションを**新手法として独立評価**する。

全球37,104種・WCVP在来群集・LGM気候類似性との因果的花色結論を今回の1枚で更新しない。13画像は非無作為のFCP失敗だけなので、独立した花色代表標本ではない。
