# MOIS：WCVP導入記録と写真9色の属内生態学的検証（2026-11-18）

## 結論
在来・導入植物相の白色組成差について、格子単位だけでなく、受容植物種1行の「WCVPに導入地域が1つ以上記録されるか」を新しく検証した。

元37,104 accepted species、Kew WCVP accepted exact binomial 36,762種。原産地域のWCVP native記録が1つ以上あり、現在のGBIF分布域気候・植生・記録努力が揃う **36,411種・6,562属** が解析母集団。うちWCVP導入地域記録あり6,842種。白写真色20,551種、赤写真色1,193種。

**新しい結果は、全球単純集計と同属内の導入記録が異なる関係を示すこと。**白は単純集計で導入記録あり19.81%（非白17.47%）だが、同属内で原産域地域数・温度/降水/VPD・日射・風・NDVI・木質AGB・GBIF観測努力・分布格子数・写真statusを調整すると、種等重みで−0.995pp（CI −2.006〜+0.017、p=.054）、属等重みで−2.452pp（−4.624〜−0.280、p=.027）。方向が逆転し、属・環境構成が全球単純比較に大きく影響する。

## 赤色写真ラベルの探索的な導入記録偏り

9色をそれぞれone-vs-restで属固定効果・属cluster SEを算出し、9比較BHを適用すると赤のみ補正後q<.05。赤vs他8色の調整済み導入記録確率差 **+5.241pp（95%CI +2.426〜+8.055、p=.000262、q=.002362）**。

| 赤色の同属内比較 | 調整済みリスク差 | 95%CI | p |
|---|---:|---|---:|
| 種等重み・全体 | +5.241pp | +2.426〜+8.055 | .000262 |
| 属等重み | +6.782pp | +0.835〜+12.728 | .0254 |
| 写真statusを除く | +5.903pp | +3.088〜+8.718 | .0000396 |
| WCVP原産域2地域以上 | +6.837pp | +3.334〜+10.341 | .000131 |
| 導入地域が最低2地域という厳格な応答 | +3.668pp | +1.227〜+6.109 | .00323 |
| 赤色種の多い上位10属を除外 | +5.544pp | +2.403〜+8.686 | .000543 |
| **赤vs白：実際に両色と導入status変動がある同属のみ** | **+6.135pp** | **+2.885〜+9.385** | **.000216** |

赤vs白の直接比較は4,961種・222属。重要なのは、赤色種の導入記録率の単純割合は **214/1,193=17.94%** で白色の19.81%より低いこと。同属・環境・原産地域数を調整すると相対的に赤が高くなる。導入後に花色が進化した結果ではなく、種構成と記録状態の条件付き対応である。

高い写真信頼度として3独立観察で単色コンセンサスを持つ赤色種は**27種のみ**。この選抜群では同属内で導入あり・なしを比較する十分な属がなく、上記の色の結論は独立に花被色が認証されたデータでは未確認。事後的な9色探索の赤を確証済み進化法則とは呼ばない。

## 属外予測の独立検証

同じ36,411種・6,562属を3fold完全属分離したL2ロジスティック（学習foldで標準化）。

| 目的変数＝WCVP導入地域記録あり | AUC | log loss |
|---|---:|---:|
| 気候・植生・分布域・原産地域数・記録努力 | 0.909680 | 0.274844 |
| ＋白写真色 | 0.909734 | 0.274779 |
| ＋赤写真色 | 0.909860 | 0.274595 |
| ＋白・赤 | 0.909851 | 0.274598 |

赤を足すlog loss差は−0.000249、属bootstrap2000回95%CI [−0.000529,+0.000006]で0を含む。**赤が既知属内の導入記録と対応するが、新属への予測情報としては追加利得が極めて小さい。**

## 生態学的な意味と限界

今回の分析は「導入地域で白が多い」という既存の同一100km格子観察が、単なる普遍的な白色種の導入優位ではないことを明らかにした。形質が環境に直接適応した効果、鳥媒・ハチ媒など送粉ギルドによる選択、原産域での花色変化ではなく、**分類群・原産域・導入記録の結びつき**を検証したもの。

特に、種別写真赤ラベルが送粉者視覚や鳥媒を意味することはない。送粉ギルドと導入先の独立した記録を本解析は用いていない。WCVPの「導入記録なし」は真の非導入、未定着を必ず意味しない。WCVP native/introducedは広域TDWG Level 3であって実際の現地個体の野生状態や輸送経路・時間を保証しない。全球GBIF種分布は撮影された花色の場所ごとの真値でもない。

次の生態学的な一つの主目標は、独立した地域分割と送粉ギルドを使い、赤の属内シグナルが生物地理的に再現するか事前固定して検証すること。閾値や分類群を有意になるまで選び続けない。
