# MOIS：在来域だけの種プールと、同一セルの在来・導入比較

解析日：2026-11-22 JST。PR #206 の既存解析を継続する。ユーザーの追加仮説は「長い群集形成の履歴と、導入後の分布拡大・再集合の違い」。この文書は今回の計算前に解析上の選択を記録するものであり、正式な事前登録ではない。これまでの結果を知った上で設計した追加解析である。

## 1. 現在地と今回の主目標

前回の在来9色解析は在来種だけの群集を評価したが、色を交換する種プール、占有幅、地理親和性は全GBIF分布で定義していた。今回の主目標は、この帰無モデルの定義への頑健性を検証し、同じ場所の在来・導入群の差を共通の帰無モデルで直接測ることである。

固定入力は37,104元specieskey、5,493,931種×100kmセル、18,577セル。WCVPは在来・導入状態の付与にのみ使い、元specieskeyを統合しない。厳格在来2,271,852ペア、厳格導入436,422ペアを再現する。写真由来9色ラベルを変更しない。

## 2. 在来域だけで定義する種プール

strict-native に1ペア以上存在する種だけを交換候補とし、各種の在来セル数から幅の5帯（1、2–5、6–20、21–100、101以上）を作る。地理親和性も同じ在来ペアから計算する。1つの座標区分が在来占有セルの65%以上ならその区分、それ以外は複数区分型とする。

主モデルは属×在来占有幅×在来6区分親和性、感度分析は属×在来占有幅である。6区分は経度−30度と60度で分けた3帯と南北の組合せであり、生物地理区やTDWG3ごとの地域種プールそのものではない。今回はstrict-nativeに対象を限定し、moderate独自の種プール再定義は実施しない。

9色と白固定8色を各999回実行する。8色では元の白色種IDと非白種×セル構成を固定する。観測群集、各セルの種数、種の占有セルは全反復で固定する。各反復で種ごとに1つの色だけを割り当て、同じ種には全セルで同じ色を使う。

主モデルの4統計、すなわち9色平均・8色平均・9色の南−北・8色の南−北をHolm4の1族として扱う。平均は各セル30種以上、8色では非白30種以上。100種基準、6区分等重み、個別区分、北極−北方温帯、非地理モデルは感度分析または探索結果として区別する。

交換可能な種数、元ペアのうち色が変わり得る割合、単色層などで固定される割合を保存する。前回との変化にはdonor・幅・親和性・交換可能集合の変更が含まれるため、変化全体を単一の地理効果に帰属させない。

## 3. 同一セルの在来・導入比較

主対象はstrict条件で在来・導入の双方が30種以上ある同じセル。9色では既存の3,106セルを再現する。8色は双方の元の非白色種が30以上ある共通セルを使う。片方だけに適用した閾値や、両群で異なるセル集合を比較しない。

各セルの差を在来−導入で定義し、同じ重みで集約する。

\[
D_{obs}=mean_c(H_{native,c}-H_{introduced,c}),\quad
\Delta D=D_{obs}-mean_b(D_b).
\]

正の偏差差は、導入群の方が帰無期待に対して相対的に色が集中している方向を示す。負なら在来群の方が相対的に集中する。生のShannon差、帰無期待差、偏差差を別々に保存する。

比較には共通の全GBIF種プールを使う。主モデルは既存の属×全GBIF占有幅×6区分親和性、感度分析は属×全GBIF占有幅。各反復の同じ種ラベルを在来・導入およびstrict・moderateに共通適用する。同種が場所によって異なる在来状態を持つため、両群を独立にはシャッフルしない。在来限定nullと別の導入限定nullの残差を引く設計は採用しない。

主検定は地理条件付きモデル・strict・30種基準・セル等重みの9色と白固定8色で、Holm2を適用する。以下を感度分析として同じ置換から計算する。

- 各セルの少数側の種数を重みにする。
- 両群100種以上に制限する。
- moderateの重複集団で再評価する。
- 9色を8色の適格セルと同じ集合に制限する。

9色の構成比は各セル内の種割合を先に求め、主結果と同じセル等重みで平均する。全ペアを一括した構成比へ置き換えない。色別構成比は記述結果であり、色別の追加検定は主検定族に含めない。

## 4. 推論と検証

999反復の順位型pを使う。下側は (1 + 模擬値≤観測値の回数)/(B+1)、上側も同様、両側は2×小さい片側pを1で打ち切る。同値判定の許容差は1e−12。帰無平均のMonte Carlo標準誤差を保存する。模擬値の95%区間は帰無参照区間であり、効果の信頼区間とは呼ばない。

Holm4とHolm2は異なる問いについての個別の検定族であり、プロジェクト全体の多重性を制御したとは書かない。各モデルの全反復統計、セル別期待値、元資料のSHA、コードのSHA、実行環境、固定マスクと種プールの監査を保存する。元資料・観測値・前回999反復の在来期待値を再現できる箇所は数値ゲートにする。別モデルで同じseedを使っても、モデル間の反復を対応差として検定しない。

## 5. 時間仮説への接続と限界

在来・導入状態は滞在期間の実測値ではない。今回のデータは導入年代、拡散速度、個体群増殖率、種分化を測っていない。「放散」は現段階では導入後の分布拡大・群集再集合という仮説として扱う。適応放散や長期選択を同定したとは結論しない。

差の候補説明には、導入時の人為的選別、導入頻度、生活型、原産地、定着後の環境選別、写真色の測定誤差がある。現在の属・占有幅・粗い地理条件付けはその一部への比較であり、全てを除いた時間効果ではない。導入履歴を直接付加できれば、滞在期間に伴う色組成や集中度の変化という別の問いに進める。
